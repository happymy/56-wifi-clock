# 联网时钟功能总结

> **原版产品规格（参考）**：本文档记录**原版**「56WiFi时钟」的出厂功能，作为复刻对照基准。本复刻固件（`firmware/STC`）**复刻整屏三态**（TIME `HH:MM` / DATE `MMDD` / TEMP `[符号][2位温度][C/F]`），**手动 UP 切换**（单击循环、双击恢复走时，无自动整屏轮显），并在 TIME 态以 **SMG1 子轮换 温度°C/星期**（由 8266 `cycle_flags` 控制）；详见 `plan/新版时钟功能.md` §一。与原版差异：原版为**自动**整屏轮显（`cycle_flags` 控整屏），本固件改为**手动 UP 切整屏** + SMG1 子轮换；大屏温度支持 °C/°F（°F 由 `cfg.temp_unit` 切换，SMG1 温度恒°C）；「显示模式 0/1」在本固件中映射为手动 UP 三态。

## 一、核心显示功能

- **时间显示**：通过 4 位 1.2 寸数码管和 2 位 0.56 寸数码管显示时间（时、分、秒）。
- **日期显示**：支持日期显示。
- **温度显示**：通过热敏电阻（RM1）检测环境温度并显示。

## 二、显示模式（SY）

- **模式 0（固定显示）**：固定显示当前界面，不自动切换。
- **模式 1（自动切换）**：自动循环切换时间、日期、温度三个界面的显示。

## 三、亮度调节（Lu）

- **自动亮度（0 档）**：通过光敏电阻（R9）检测环境光线，自动调节屏幕亮度。
- **手动亮度（1~8 档）**：用户可手动设置 1~8 级固定亮度等级。

## 四、温度补偿设置（Ao）

由于元器件差异和芯片发热等因素导致温度测量不准，可通过此功能进行温度补偿校准。

- **补偿范围**：-8°C 至 +8°C。
- **计算公式**：设置后实际显示温度 = 实测温度 + 补偿值。

## 五、闹钟功能（三组独立闹钟）

- 双击 **SET** 键进入闹钟设置选项。
- 共支持三组独立闹钟，可分别设置时间和开关状态。
- 最后一位参数：0 为关闭，1 为开启。
- 闹钟触发时通过蜂鸣器（BUZZER1）发出声音提醒。

## 六、时间设置

- 长按 **SET** 键进入时间设置选项。
- **联网状态下**：无需手动设置，系统自动通过 WiFi 获取网络时间。
- **未联网状态下**：支持手动修改时间和日期。

## 七、WiFi 联网功能（ESP8266 模块）

- 内置 ESP8266 WiFi 模块，自动连接网络获取标准时间。
- **配网方式**：连接时钟自带的“56dz network clock”热点（密码：56dz.com），浏览器访问 192.168.4.1 进行配置。
- **时区选择**：支持全球时区选择（如 UTC+8 中国标准时间等）。
- **WiFi 频段限制**：仅支持 2.4GHz 频段 WiFi，不支持 5GHz。
- **自动重连**：配网成功后，每次上电自动连接 WiFi，无需重复配网。
- **热点自动开关**：配网成功后热点自动关闭；若原 WiFi 不可用，热点自动重新开启，方便重新配网。
- **WiFi 状态指示灯**：闪烁表示正在连接，常亮表示连接成功，不亮表示连接超时。
- **时钟同步指示灯**：点亮表示时钟已同步网络时间。

## 八、断电时间保持（备用电池）

- 内置 CR1220 纽扣电池为 DS1302 时钟芯片供电，即使主电源断开，时间仍能持续运行。
- **注意**：电池有字一面为正极，正极朝上安装。

## 九、其他硬件特性

- 采用 STC15W408AS 单片机作为主控。
- 采用 TM1639 芯片驱动数码管。
- 采用 AMS1117-3.3 稳压芯片为系统供电。
- 支持通过 Micro USB 接口供电（5V DC）。
- 配有两个轻触开关（SET、UP）用于按键操作。
- 配有红色贴片 LED 指示灯（LED1）；另有 LED6 蓝色指示灯由 ESP-01S(ESP8266) 驱动。

## 操作方式速查

| 按键操作 | 功能 |
| --- | --- |
| 单击 SET 键 | 进入显示设置（显示模式、亮度、温度补偿） |
| 双击 SET 键 | 进入闹钟设置（三组独立闹钟） |
| 长按 SET 键 | 进入时间设置（手动修改时间） |
