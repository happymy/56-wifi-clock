## 烧录（真机已验证，避免踩坑）

> 本机 `pio` 不在 PATH，一律用 `python -m platformio`（Core 6.1.19）。**不要用 `pio run -t upload`**：该流程按 GPIO0 拉低进下载模式设计，本项目接自动下载器（DTR/RTS 硬复位时序），esptool 默认复位方式与其不匹配会烧录失败/挂起；本机实测唯一的可靠路径是直接调 esptool.py。

```powershell
# 1) 构建（在 firmware/8266 下）
python -m platformio run

# 2) 烧录（自动下载器接 COM3；--before default_reset 走 DTR/RTS 硬复位，成功即自动进下载模式）
python "C:\Users\GAME\.platformio\packages\tool-esptoolpy\esptool.py" `
      --port COM3 --baud 921600 --before default_reset `
      write_flash 0x0 ".pio\build\esp01_1m\firmware.bin"
```

- 成功标志：末行 `Hash of data verified.`，替换前旧固件残片不回读（不校验旧内容）。
- esptool.py 路径固定于 `.platformio/packages/tool-esptoolpy/`，若换机器重装 PlatformIO 用 `python -m esptool` 命令代替（写法`--before default_reset write_flash 0x0 固件`一致）。
- 烧录用 921600 波特率（ESP8266 支持）；串口必须是空闲的自动下载器，普通 USB-TTL 需手动 GPIO0 拉低，命令不变。
- 烧录后伪待机默认 2min Web 窗口：需 51 `REQ_TIME`（双击 SET）唤醒连 STA 后页面（`http://<STA_IP>`）可达，见 `plan/8266串口测试计划.md`。
- 容量红线：Flash 按 `eagle.flash.1m.ld`，上传上限 761840B，当前固件 ~310KB（31%），余量充足。

## 容量与资源红线（硬件冻结）

- **Flash 1MB（8Mbit）**：`eagle.flash.1m.ld`（1M no SPIFFS/OTA）→ 程序区约 **762KB**（上传上限 761840B）、EEPROM 模拟 16KB。**不用文件系统**，Web 页面全部 PROGMEM `F("...")`。
- **RAM 用户堆约 80KB**（IRAM 受 lwIP/缓存占用）：Web 响应一律 `F()` 存储、避免大 `String` 堆碎片（需要拼接用 `+`) 前先 `reserve()`）；**禁止引入任何 JS/CSS 大框架**（jQuery/Bootstrap 等）。HTML 用原生 `<form method=post>` + 服务端输出 `<select>`/输入框。
- **UART1（P3.0/P3.1 对 51）9600 8N1**：与 51 唯一链路，无调试串口。调试输出只经 `Serial` 同一条线——产品运行时 UART1 专供 51，**禁止任何非协议打印**（会污染 51 帧解析）。

## ⛔ 铁律（经 51 端实测踩坑，勿重犯）

1. **SET_CFG 完整 54B 镜像**：51 收到 `SET_CFG(0x82,54B)` 整体覆盖内存 `cfg` 并入 EEPROM，**不做字节级合并**。8266 必须维护**完整 54B 镜像** `g_cfg[54]`：上线先发 `REQ_CFG(0x87)` 拉 51 当前值作底；Web 改某字段只改镜像对应字节，再整帧 `SET_CFG(0x82,54B)` 下发。**严禁只下发想改的字节其余填 0**——否则清空 51 `bright_mode/bright_lvl` 等按键值。
2. **闹钟时/分为 BCD**：`SET_CFG` 字段 alarm[3][3] 的时/分存 BCD（与 DS1302 同格式，51 直读直比）。Web 表单收十进制后在镜像写入前必须 `dec→BCD`（如 15→`0x15`）；回显时 `BCD→dec`。下发 `0x0F`（二进制15）与 51 读回 BCD `0x15` 永不相等，**闹钟静默不触发**。
3. **DISP_OVERRIDE(0x89) mode1 的 mm/ss 为十进制值字节**（0–99），不是人类可读十六进制。45 秒传 `0x2D`，传 `0x45`=69 会显示 `03:69`。
4. **mode2（归零响铃）只响铃、不接管/释放显示**；显示接管释放**只能靠 mode0 帧**。51 设备键 `CD_CTRL(0x05)=1`（取消）只是上行请求，**不清 51 本地 `cd_disp`**——8266 收到取消后**必须回发 mode0** 才能真正恢复时钟显示。
5. **伪装待机 UART 始终在线**：伪待机 CPU 常驻、RF 关，UART 外设始终有时钟，51 任意帧都被正常接收，无唤醒延迟。**永不 deep-sleep**（硬件无唤醒线）。`WiFi.forceSleepBegin()` 只关 RF，不关串口。
6. **BOOT 时机**：固件启动、UART 就绪后**尽早发 `BOOT(0x8F)`**（51 上电 ~2s 握手窗口内判定在线）。流量达标后 51 才接受 `SET_TIME/SET_CFG/NET_STAT/STA_IP`。
7. **读 EEPROM 永远先判擦除态 `0xFF`**（真机首烧/desoldered 旧片必踩）：
   - **擦除仅此一次**：只有"旧片/二手片首次烧入"需要手动 `erase_region 0xFB000`（旧数据可能残留 `0x5A` 等），**或** Web `ENTER_AP` 清凭据。此后**固件升级、重新配网一律不需要再擦除**——正常写路径（`store_save_wifi`/`store_set_ap_pwd`）永远写 0 终止串，升级固件不覆盖 EEPROM 区，千万别顺手连配置一起擦。
   - 教训①：`store_get_ap_pwd()` 原判 `buf[0]?buf:"12345678"`，擦除后首字节是 `0xFF`（非 0），于是把 16 个 `0xFF` 当 AP 密码——**AP 能搜到但任何密码连不上**。修复：`(buf[0]==0xFF || buf[0]==0) ? "12345678" : buf`。
   - 教训②：`wifi_tz_h()` 对 `g_cfg[13]`（tz）判 `-12..14` 有效，擦除态 `0xFF` 读作 -1 **能通过范围检查**，窗口期把时区推成 -1（51 在线 `REQ_CFG→SET_CFG` 回填后自愈，未修）。通则：**凡读取 EEPROM 的"有效性"判断，必须显式排除 `0xFF`（擦除）和 `0x00`（空串）两个哨兵**，不能只靠"非 0"或范围白名单，MAGIC 只保护 blob 不保护 Wi-Fi/AP 字符串区。

## 协议命令速查（来自 plan/串口通信协议.md §3，8266 侧视角）

| 命令 | 方向 | 载荷 | 8266 职责 |
| --- | --- | --- | --- |
| `0x01` REQ_TIME | 51→ESP | — | 应答：临时连 STA → NTP → `SET_TIME`（若已同步直接发最近值） |
| `0x02` HEARTBEAT | 51→ESP | — | 应答 `0x83 NET_STAT`（当前网络状态） |
| `0x03` BTN_EVENT | 51→ESP | 1B | 可选；暂不消费（51 未实现） |
| `0x04` ENTER_AP | 51→ESP | — | 双键≥5s：清 STA 凭据→恢复默认 AP 密码→重启进 AP 配网→回 `0x84 AP_READY` |
| `0x05` CD_CTRL | 51→ESP | 1B | 倒计时控制：0=暂停/恢复，1=取消（取消后**必须回发 mode0**） |
| `0x81` SET_TIME | ESP→51 | 8B BCD | 下发本地时间（含 tz） |
| `0x82` SET_CFG | 双向 | 54B | 收=存镜像+落盘；发=Web 改后整帧推 51 |
| `0x83` NET_STAT | ESP→51 | 1B | 0未连 1连接中 2已连 3已同步 |
| `0x84` AP_READY | ESP→51 | — | 进 AP 配网完成 |
| `0x87` REQ_CFG | ESP→51 | — | 上线拉取 51 当前配置 → 51 回 `0x82` |
| `0x88` STA_IP | ESP→51 | 4B | STA 获得 IP 后上报（51 缓存末段） |
| `0x89` DISP_OVERRIDE | ESP→51 | 1–3B | mode0 释放 / mode1 `[1,mm,ss]` 每秒一帧 / mode2 归零响铃 |
| `0x8F` BOOT | ESP→51 | — | 启动即发，51 判定在线 |

帧格式：`[0xAA][0x55][CMD][LEN][PAYLOAD...][CHK]`，`CHK=XOR(CMD,LEN,PAYLOAD..)`；帧间 ≥5ms；51 无 ACK/NAK，请求/应答超时 1s 重发≤3。

## 系统状态机（调度）

```
PSEUDO (CPU跑 RF关) ───────────────────────────────┐
   │ 触发: 上电/每日00:00/12:00/51 REQ_TIME         │
   ▼                                              │
STA_CONNECT → NTP 对时 → SET_TIME(51) → STA_IP(51) │
   └ 关联后闲置 2min 自动断 STA                    │
   └ STA 连不上时: 开 AP 配网(56dz network clock)   │
        AP 常开直到某客户端 POST 成功配网 → 关 AP    │
        STA 连上后 AP 立即关(配网一次性)            │
 伪待机收到 51 任意帧→按命令处理, 不唤醒 RF         │
```

- LED_WIFI（如用）伪待机灭、RF 工作亮；56dz 板上 51 侧红灯逻辑由 `led_en` 控制，8266 只发 `SET_CFG`。
- 对时授权：8266 为本地时间权威，`configTime(tz,0,ntp,..)` → `time(nullptr)` → 换算 BCD → `SET_TIME(0x81)` 8B。DST 在换算时叠加。

> - **ENTER_AP 行为**：`wifi_ep_ap_mode()` 清 STA 凭据（`store_save_wifi("","")`）后 `ESP.restart()` → 重启无凭据直接开 AP，即计划 §3"清凭据→重启进 AP"；配置项 `debug_uart`（51 g_cfg debug）与 8266 无涉。

> - **Web 根页运行时分流**：`web_setup(bool)` 的参数已废，改为 `h_root()` 按 `wifi_ap_active()` 判断返回 AP 配网页或 STA 全功能页。
> - **chunked Web 响应修正**：`h_sta_root` 用 `setContentLength(CONTENT_LENGTH_UNKNOWN)+send(200,HT,"")` 开场后 `sendContent` 流式（ESP8266WebServer 要求，否则无响应头）；单页小响应一律 `send_P/send`。

### E1 协议层 `src/proto.h/.cpp`
- 常量：SYNC/命令码/`CFG_LEN 54`；`uint8_t g_cfg[CFG_LEN]` 配置镜像。
- `proto_rx(uint8_t b)`：逐字节状态机解析 `AA 55 CMD LEN PAYLOAD CHK`，校验 XOR，分发到回调。
- `proto_send(cmd, payload, len)`：组帧 + `Serial.write`，帧间隔 ≥5ms。
- 上行命令封装：`send_boot()`、`send_set_time()`、`send_set_cfg()`、`send_net_stat()`、`send_sta_ip()`、`send_disp_override()`。
- 接收处理：`REQ_TIME`→对时；`HEARTBEAT`→上送 NET_STAT；`ENTER_AP`→进入 AP 配网流程；`CD_CTRL`→倒计时逻辑（0 暂停/恢复 tick，1 取消→回发 mode0）；`0x82 SET_CFG`→**整帧拷入 `g_cfg`**+EEPROM 备份，并同步 Web 上次表单值（回显）。
- `REQ_CFG` 为 8266 主动发（51 回 `0x82`）→ `proto_on_set_cfg` 入口置 `cfg_valid=1`（标志镜像已从 51 拉到）。
- 验收：Python 自检 `test/test_proto.py` 帧编解码与 51 `uart_8266_sim.py` 常量一致；与 51 联调 BOOT→REQ_CFG→回 54B 无字节错位。

### E2 持久化 `src/store.h/.cpp`
- 用 Arduino `EEPROM`（模拟 16KB）：存 ①WiFi STA 凭据（SSID/密码，~64B）②AP 密码 ③`g_cfg[54]` 备份镜像 ④倒计时预设 ⑤上次 Web 表单（可省）。`EEPROM.begin()` 一次、`commit()` 节流。
- 写前先读比对，避免无谓擦写（25Q 擦写磨损）。
- 验收：掉电重启后凭据/镜像仍在；自检 `test/test_store.py`（mock 或实读回环）。

### E3 伪待机与对时 `src/wifi_task.h/.cpp`
- `wifi_enter_pseudo()`：`WiFi.forceSleepBegin()`（仅关 RF，UART 常驻）。
- `wifi_sta_connect()`：`WiFi.forceSleepWake()` → `WiFi.begin(ssid,pwd)` → 超时失败回伪待机。
- NTP：`configTime()` 失败按列表递进（国内 3 + 国外 2）；`time(nullptr)`→本地时间→组装 `SET_TIME`（时区 BCD 换算，DST 叠加）。两个 list 写死 PROGMEM。
- 调度：上电同步一次；软件时钟到每天 00:00/12:00 触发；51 `REQ_TIME` 随时触发；STA 使用后 **闲置 2min 自动断回伪待机**。
- 验收：伪待机功耗 <20mA；压力下 `esp_get_free_heap()` >30KB。

### E4 倒计时权威 `src/countdown.h/.cpp`
- Web 设时长启动 → 维护 `cd_remaining_s` tick；每 1s `send_disp_override_mode1(mm, ss)`（**十进制字节**）。
- 归零：`send_disp_override_mode2()`（仅响铃，不接管显示）；倒计时显示接管期间 51 时钟被覆盖，归零后**回发 mode0** 恢复走时。
- `CD_CTRL=0`：切换 暂停/继续（tick 停止/恢复；暂停时**不**发帧，保持最后画面？——按协议 51 每 1s 收到的 MM:SS 静态停更即暂停，无需额外帧）；`CD_CTRL=1`：取消倒计时并**回发 mode0**。
- 验收：Python 自检 tick→帧序列；与 51 `uart_8266_sim.py cd/cdctrl` 语义对齐。

### E5 Web `src/web.h/.cpp`（两页分离，`ESP8266WebServer`）
- **AP 配置页**（`softAP("56dz network clock")` → `192.168.4.1`）：仅一个 `<form method=post>` 填 WiFi SSID/密码；提交成功 → 存凭据 → 尝试连 STA → 连上即关 AP（配网一次性）；失败停留本页提示。**本页不设任何其余配置项**。
- **STA 配置页**（STA 同网段 IP，双击 SET 显示的地址；页面 `<a>` 提示）：全功能单页表单，默认值回填自 `g_cfg` + 上次值：
  - 大屏主模式 `display_mode`（固定 TIME / 自动轮播）
  - 亮度 `bright_mode`（自动/手动）+ `bright_lvl`（1–8）
  - 温度单位 `temp_unit`（°C/°F）、温度补偿 `temp_offset`（有符号整数 °C，-8~+8，参考当前环境温度手动酌定）；51 协议无 NTC 上报命令，不做自动标定
  - SMG1 选显 `smg1_mode`（温度/日期）
  - 闹钟 3 组：on + 时/分（表单十进制，镜像写 **BCD**）
  - 时区 `tz`（有符号，默认 +8）
  - 关屏时段 `off_start/off_end`（起/止 时+分，`0xFF`=禁用）
  - 贪睡 `snooze`（0/5/10）
  - 状态灯 `led_en`
  - 倒计时：预设分钟（1–99）+ 「开始/暂停/取消」按钮（本地管理，经 0x89/CD_CTRL 帧驱动 51）
  - 状态行：51 在线 / STA IP / 最后同步时间
- 提交统一入口：解析 POST → 改 `g_cfg` 对应字节（含 BCD 换算）→ `send_set_cfg(g_cfg,54)` → 回显「已保存」。
- 内存纪律：每个 handler `server.send_P`/`F()` 片段式输出，禁拼大 String；缺省 `Content-Type: text/html; charset=utf-8`。
- 验收：手机浏览器小白可用；AP 页配网成功即关 AP；STA 页改亮度 → 51 亮度变化；改闹钟 15:05 → 51 到时响。

### E6 主循环整合 `src/main.cpp`
- `setup()`：串口 9600 → EEPROM.begin → 读凭据 → `send_boot()` 尽早发 → 伪待机/首次对时 → 若 STA 未配网立即开 AP。
- `loop()`：`proto` 字节灌入 → 帧分发；1s 调度（倒计时 tick/对时触发/闲置 2min 计时/Web 重启）；若 AP 开则 `server.handleClient()`；RF 关时无 Web 服务（伪待机期间 Web 页面不可达，只收串口）。
- 心跳联动 2min 闲置：最后一次 RF 使用时刻，超时 `forceSleepBegin`。
- 验收：上电 BOOT→51 握手成功；Web 交互全链路；停电恢复自动回位。
