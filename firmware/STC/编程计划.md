# 51 产品固件编程计划（STC15W408AS → firmware/STC）

> 范围：仅 51 侧产品固件，集成显示 / RTC / 按键 / 传感器 / EEPROM / UART 协议。
> 参考权威（按优先级）：`plan/原理图.md`、`plan/串口通信协议.md`、`plan/固件复刻计划.md`、`plan/新版时钟功能.md`、`doc/原版时钟功能.md`，以及 `demo/_common` 已烧录验证的驱动（`tm1639.c/.h`、`ds1302.c/.h`、`stc15.h`）。
  > 构建：复用 `demo/_common` 驱动，`firmware/STC/build.bat` 调用 SDCC（`-mmcs51 -I../../demo/_common --code-size 8192`，固件区上限 8192B/8KB）。

## ⛔ 安全红线（贯穿所有模块，违反即焚硬件）

1. **P3.0/P3.1 严禁强推挽**：绝不写 `P3M0 |= 0x02`（TX）或 `P3M1/P3M0` 将其置 01。两引脚保持复位默认**准双向**（位=00）。demo 的 `uart-test`/`ds1302-clock` 里 `P3M0 |= 0x02` 是回环测试遗留，**产品固件必须删除**。
2. **BEEP(P2.1) 允许推挽**（不连 ESP，安全），但上电务必先 `BEEP_OFF()`（active-low：高=静音）。
3. **TM1639 三线（P2.3/2.4/2.5）保持准双向**（板载 10K 上拉已够），写时序用 `tm1639.c`，不另设推挽。
4. **DS1302 三线（P1.3/1.4/1.5）准双向**，沿用 `ds1302.c`。
5. **EEPROM 地址范围 0x0000–0x13FF**，配置区与日志区分扇区；IAP 操作关中断、`IAP_CONTR=0x84`、触发 `0x5A→0xA5`、结束 `iap_idle` 防误写。
6. **上电 `delay_ms(200)` 再发 TM1639 首命令**；DS1302 首读前 `delay_ms(500)`。
7. **T0=TM1639 极暗 PWM（12T）**、**T2=UART1 波特源（9600 8N1, T2L=0xE0,T2H=0xFE,AUXR=0x14,AUXR|=0x01）**；**STC15W408AS 无 Timer1**，绝不分配；不抢占 T0/T2 用途。

## 显示与引脚约定（来自 `demo/_common` + `plan/原理图.md`）

- `disp[0..7]` 对应 `GRID1..GRID8`：
  - GRID1=disp[0] 主屏1(LED2)，GRID2=disp[1] 主屏2(LED3)，**GRID3=disp[2] 主屏3(LED4) 物理倒装→`seg_rotate180`**，GRID4=disp[3] 主屏4(LED5)
  - GRID5=disp[4] SMG1 右(个位)，GRID6=disp[5] SMG1 左(十位)
  - GRID7=disp[6] SMG2 右(个位)，GRID8=disp[7] SMG2 左(十位)
- 段：`seg_font[16]` 共阴（bit 序 dp,g,f,e,d,c,b,a）；TM1639 每 GRID 发 2 字节（低=SEG1-4 a-d，高=SEG9-12 e-g,dp）。
- 亮度：`tm1639_set_brightness(lvl 0..7)`；自动亮度 `tm1639_set_light(adc0)`（暗区叠加软件 PWM，不灭不闪）。
- 按键：`UP=P3.2`、`SET=P3.3`，active-low 内部上拉，准双向。

## 模块分解（按构建顺序，每模块独立编译验证）

### M0 工程骨架 + 上电时钟显示
- 建 `firmware/STC/src/main.c`、`firmware/STC/build.bat`（-I../../demo/_common）。
- `main()`：`BEEP_OFF()` → `delay_ms(200)` → 初始化 ADC/P1.0,P1.1 高阻 → `tm1639_init()` → 显示先出 → `delay_ms(500)` → `ds1302_init()` → 主循环：读 DS1302、渲染时钟（大屏 HH:MM + SMG2 秒 + SMG1 温度/日期，SMG1 由 `smg1_mode` 固定选显）、写屏、250ms tick。
- 验收：编译零错；上电显示时间、秒走时、日期。

### M1 显示布局模块 `display.c/.h`
- 渲染函数：整屏三态 `DISP_TIME`/`DISP_DATE`/`DISP_TEMP`（手动 UP 切）——大屏 TIME `HH:MM`(冒号=GRID2/GRID3 小数点，GRID3 倒装)、DATE `MMDD`(月左/日右镜像)、TEMP `[符号][2位温度][C/F]`(°F 由 `cfg.temp_unit` 切，SMG1 温度恒°C)；SMG2 TIME 显秒/ DATE 显年份/ TEMP 灭；SMG1 仅 TIME 态由 `smg1_sel` 选 **温度 °C**（个位 GRID5 小数点恒亮）/ **日期(日 DD)**，DATE 显星期/ TEMP 灭。SMG1 选显由 `smg1_mode` 经 `smg1_rot` 固定决定（不轮换）。
- 导出 `disp_render(t, temp_x10, smg1_sel, disp[8])` 供主循环调用。
- 验收：编译零错；各模式显式正确（GRID3 倒装、左右位顺序）。

### M2 亮度调节（单击 SET）
- 单击 SET 进亮度调节：大屏闪显档位，UP 加减（`0=自动光敏,1–8=手动`），再次单击 SET 确认退出。
- 写入 `cfg.bright_mode/bright_lvl` 并 EEPROM 持久化（M7 前先用 RAM 占位，M7 落盘）。
- 验收：编译零错；档位变化、自动档生效 `tm1639_set_light`。

### M3 手动时间设置（长按 SET）
- 长按 SET 进设置：时→分→秒→年→月→日 闪烁，UP+，单击 SET 移位/退出写 DS1302。
- 手动设日期按真实月末封顶（大小月正确；Feb 恒 28，闰年 2/29 由 8266 对时校正，省 CODE 不入闰年表）。
- 验收：编译零错；设置并掉电后时间连续。

### M4 计时器（长按 UP 切换）—— ✅ V1 已实装（51 原生）
- 长按 UP 进入/退出计时器；计时态单击 UP 在 运行/暂停 间切换，SET 复位为 00:00；时基复用 1s tick，封顶 `99:59`。**首秒不漏/不快**：起动时捕获当前 DS1302 秒 `tm_last=t.sec` 为基准。主循环 `put_mmss` 渲染。

### M5 倒计时 —— 已移至 8266
- 倒计时由 8266 负责，51 仅显示 8266 每 1s 推送的 `MM:SS`（见 `DISP_OVERRIDE`）。**双击 UP 在 51 端不再有功能**（原「双击 UP 进入/退出倒计时设定态」已移除，倒计时设定/记忆在 8266/Web）。

### M6 传感器：光敏 + 热敏温度
- 光敏：`tm1639_set_light(adc0)` 自动调亮度（沿用）。
- 热敏：NTC→温度（Steinhart-Hart 或查表，10 位 ADC P1.1），叠加 `cfg.temp_offset` 有符号补偿，`cfg.temp_unit` 选 °C/°F。
- 验收：编译零错；温度随热敏变化、`temp_offset` 生效。

### M7 配置持久化 `config.c/.h` + EEPROM
- 54B 配置结构（字段完全对齐 `串口通信协议.md §5`，含 3 闹钟 / 5 事项提醒 / tz / off_start/end / chime / snooze / dst / smg1_mode / cd_preset / temp_unit / bright_mode/lvl / temp_offset）。
- `cfg_load()`（默认初始化+EEPROM 读）、`cfg_save()`（擦扇区写回）、`eeprom_*` 封装（关中断、IAP 序列）。
- 验收：编译零错；写读回一致、掉电保持；地址不越界 0x13FF。

### M8 串口协议 `uart.c/.h`
- UART1 中断 + 环形缓冲；`uart_send(buf,len)` 阻塞发。
- 帧解析状态机：`AA 55 CMD LEN [PAYLOAD] CHK`（CHK=XOR 全帧）。
- 接收命令处理：`0x81 SET_TIME`（写 DS1302+tz）、`0x82 SET_CFG`（写 cfg+EEPROM+应用）、`0x83 NET_STATUS`（存状态）、`0x84 AP_READY`、`0x85 ACK`、`0x86 NAK`、`0x87 REQ_CFG`（回 0x82）、`0x88 STA_IP`、`0x8F BOOT`（置 online）。
- 发送原语：`0x01 REQ_TIME`、`0x02 HEARTBEAT`、`0x03 BTN_EVENT`、`0x04 ENTER_AP`、`0x82 SET_CFG`（应答）。帧间 ≥5ms；请求/应答超时 1s 重发≤3，失败维持原状态。
- 验收：编译零错；用 PC 终端按协议发帧能被正确解析（调试模式可验证）。
- **⛔ 安全**：uart_init **不**动 P3M0/P3M1 的 P3.0/P3.1（保持准双向）。

### M9 上电握手 + 调试模式
- 上电开 ~2s 窗口监听 `BOOT(0x8F)` 或任意合法帧 → 在线则正常模式；超时无帧 → 蜂鸣器响 3 声进调试模式。
- 调试模式：UART1 极详细日志（启动/EEPROM 54B dump/DS1302 时间/ADC 光温/按键/状态机/每字节 hex + 解析帧）；串口收到字节按协议帧解析（等同真实 8266）。
- `cfg.debug_uart` 置 1 可强制调试模式。
- 验收：编译零错；无 8266 时响 3 声并 verbose 日志；有 8266 发 BOOT 则静默正常。

### M10 闹钟 / 事项提醒 / 整点报时 / 关屏时段
- 每分钟比对 3 闹钟 + 5 事项提醒（一次性/每周/每月/每年），命中 → 蜂鸣器 30s 渐强。
- 整点报时（`cfg.chime`）：轻响 1–2 声。
- 关屏时段（`cfg.off_start/end`）：窗口内发 0x80 灭屏，窗口外恢复；关屏中单击任意键临时点亮 10s。
- 响铃中单击 UP=贪睡、单击 SET=关闭。
- 验收：编译零错；各触发条件正确、响铃不卡死主循环。

### M11 全量集成与对照验收
- 主循环整合全部模块；逐条对照 `doc/原版时钟功能.md` + `plan/新版时钟功能.md` 验收点（时间/日期/温度显示、显示模式、亮度、温度补偿、3 闹钟、手动+联网对时、WiFi 配网接口、时区、断电走时、状态灯）。
- 验收：编译零错；对照表全绿。
