# 新版 WiFi 时钟功能规格（v2，极简版）

> 基于 `doc/原版时钟功能.md` 复刻并扩展。硬件：STC15W408AS（1T 8051）+ TM1639 数码管 + DS1302 实时时钟 + ESP-01S（ESP8266，自写固件，Web 配网/校时）。
> **设计原则**：51 端按键只保留最常用、必须的功能（手动对时、亮度、计时器、倒计时、重配网）；其余设置全部放 8266 Web。界面简单、直觉、人性化。
> 配置权威在 51（EEPROM）；8266 上线拉取、Web 修改后回推。串口协议见 `plan/串口通信协议.md`。

## 一、显示与轮显

- 大屏（GRID1–4）整屏三态，**手动 UP 切换**：单击 `UP` 循环 TIME→DATE→TEMP→TIME，双击 `UP` 恢复走时（TIME）；**无自动整屏轮显**（原 `cycle_flags` 整屏控制已改由 8266 `smg1_mode` 仅控 SMG1 选显，见下）。各态：TIME `HH:MM`（冒号=GRID2/GRID3 小数点，GRID3 倒装）、DATE `MMDD`（月左/日右镜像）、TEMP `[符号][2位温度][C/F]`（NTC 无效兜底 25°C；°F 由 `cfg.temp_unit` 切换，SMG1 温度恒°C）。
- **SMG1（GRID5/6）选显**（仅 TIME 模式，由 `smg1_mode` 控制，不轮换）：`0=温度(°C)`、`1=日期(日 DD)`；由 8266 Web 固定配置，二选一常显；DATE 态 SMG1 显星期 1–7、TEMP 态灭。**SMG1 凡显温度（个位 GRID5 小数点恒亮）**。
- **SMG2（GRID7/8）**：TIME 显秒 `SS`、DATE 显年份 `YY`、TEMP 灭。
- **长按 `UP`**：进入 / 退出**计时器**（见 §四，V1 已实装，首秒不漏/不快，起动捕获当前秒为基准）。`双击 UP` 在 51 端仅恢复走时（倒计时由 8266 负责，见 §五），不再上报/预留切换。

## 二、亮度调节（51 按钮，Web 亦可）

- **单击 `SET`** 进入亮度调节：数码管闪显档位，`UP` 加减（0=自动光敏，1–8=手动），再次 **单击 `SET`** 确认退出。
- 自动档叠加极暗软件 PWM（≈1/1024，不灭不闪）。Web 端可镜像设置。

## 三、手动时间设置

- **长按 `SET`** 进入时间设置：依次 时→分→秒→年→月→日 闪烁，`UP` 加一，单击 `SET` 移位，退出即写入 DS1302。
- 联网后 ESP 对时（每日 00:00 / 12:00 或 51 主动 `REQ_TIME`）顺带 NTP 校时（`SET_TIME`，已含时区/夏令时换算）；伪待机期间不开 RF，对时才临时联网。

## 四、计时器（51 原生，秒精度）— V1 已实装

> 状态：**已实现（V1）**。51 本地计时，不依赖 8266；为塞进 8KB Flash，封顶 `99:59`（原设计 `99:59:59` 的「时」位被裁掉，见 §容量取舍）。

- **长按 `UP`** 进入/退出计时器模式。
- **单击 `UP`**：开始 / 停止（toggle，暂停态再启动继续累计）。**单击 `SET`**：复位归零（`00:00`）。
- 显示：大数码管 `MM:SS`（复用 `put_mmss`），SMG1/SMG2 空白。时基复用 T0 相位计数器派生的 1s tick，运行态每秒 +1，封顶 `99:59` 自动停。

## 五、倒计时（权威在 8266，设备端仅显示与接管）

> 容量取舍：51 原倒计时引擎（设定态 + 1s tick + `cd_preset` EEPROM 记忆）实测约 203B，塞不进 8KB。V1 把**计时权威与 tick 全部移到 8266**，51 只做显示与设备键接管，零同步代码。时长设定/记忆改由 8266 Web 或 App 负责。

- **8266** 跑倒计时，每 1s 通过 `DISP_OVERRIDE(0x89)` 向 51 推一帧 `MM:SS`；归零时发 `DISP_OVERRIDE mode2`，51 蜂鸣器响 3 声（30s 渐强，贪睡/关闭同闹钟 §七）。
- **设备端显示**：收到 `DISP_OVERRIDE` 后大屏显 `MM:SS`，SMG1/SMG2 空白；释放后恢复时钟。
- **设备键接管（P2 方案）**：倒计时显示期间，**单击 `SET`** 发 `CD_CTRL(0x05)=0`（暂停/恢复切换），**长按 `SET`** 发 `CD_CTRL=1`（取消）。其它键在倒计时显示期间被忽略。
- 原「双击 UP 进入倒计时设定态」「`cd_preset` 记忆」已移至 8266，51 不再消费 `cd_preset`（字段保留以兼容 `SET_CFG` 帧长）。

## 六、温度与补偿（8266 Web 参考温度标定）

- 51 读 NTC（RM1, P1.1）算原始温度并显示。
- **补偿 = 参考温度单点标定**：Web 输入正整数「参考温度」（如 24，即你用靠谱温度计测得的真值）；51 收到 `SET_CFG` 时读当前 NTC 原始值 `T0`，存 `offset = 参考 − T0`（有符号）。
- 之后任意时刻 `显示温度 = NTC原始 + offset`，全程线性跟随、自适应漂移，精度取决于 NTC 分辨率（优于手工 ±8 固定偏移）。
- **51 不提供手动补偿菜单**。

## 七、闹钟（3 组，Web 设置；51 响铃 + 设备键控制）

> 配置权威在 8266/Web：3 组闹钟的「开关 / 时 / 分」与「贪睡时长」**全部由 Web 设置**，经串口 `SET_CFG(0x82)` 下推 51，存 EEPROM 并即时应用（见 `plan/串口通信协议.md §5`：闹钟 `@偏移4/7/10` 各 3B = on+时+分（BCD）；贪睡 `@偏移19` = 分钟数）。**51 不提供闹钟设置菜单**，只负责到点响铃与响铃/贪睡中的设备键（贪睡 / 取消）。

### 7.1 触发（整分 0 秒）
- 51 每主循环（≈0.27s）读 DS1302；**分钟翻滚瞬间**（`t.min != last_min`）立刻比对 3 组启用闹钟的 `时+分` 与当前 `时+分`。命中 → 置 `ring_alarm=组号+1`、`ring_ticks=240`，蜂鸣器开始响。
- **保证整分 0 秒响**：比对在分钟变化后的首个主循环即执行（≤0.27s），不会漏拍、不会推迟到下一分钟。
- **多闹钟互不阻塞**：分钟比对**不**受「正在响铃 / 正在贪睡」状态门控——即使闹钟 A 正在响或处于贪睡，闹钟 B 到点的分钟边界仍正常触发 B 响铃（req1：第一个贪睡不影响第二个响）。
- 比对用 DS1302 原始 BCD（本地时），**不叠加 `tz`**（`tz` 仅由 Web 在 `SET_TIME(0x81)` 时换算好下推 51，51 只做显示/回显）。

### 7.2 响铃（脉冲鸣响，固件固定）
- 蜂鸣器 **脉冲式鸣响**：每 4 个 tick 一组，前 2 tick `BEEP_ON`、后 2 tick `BEEP_OFF`（≈0.54s 响 / 0.54s 停，**固定音量，非音量渐强**）。`ring_ticks` 从 240 递减到 0，**总时长 ≈ 65s（240×0.27s，固件固定，非 Web 配置）**；归零自动停（`ring_alarm=0`）。
- 响铃期间不影响走时 / 显示，主循环照常。

### 7.3 响铃中的设备键（仅"正在响铃"时拦截）
- 仅当 **`ring_alarm` 非零（真正在响铃）** 时拦截按键；`UP`/`SET` 单击 / 长按 / 双击任意事件类型都生效。
- **`UP` = 贪睡**：取消当前响铃，按当前闹钟组号挂起一次重响（见 7.4）。
- **`SET` = 取消全部**：停止当前响铃 + 清除所有挂起的贪睡重响（`snooze_idx / snooze_ticks = 0`），并 **蜂鸣「滴滴」两声确认**，之后不再有该闹钟的任何重响。
- 取消为**可感知操作**：`SET` 有确认音，避免「按键无反应」误判。**注意**：`SET`/`UP` 仅在响铃态有效；进入贪睡倒计时后这两个键即恢复常态（见 7.4），不再被闹钟逻辑吞掉。

### 7.4 贪睡（重响一次，时长由 Web 设）
- 触发贪睡后 `snooze_idx = 当前组号`、`snooze_ticks = cfg.snooze × 240`（`cfg.snooze` = 贪睡**分钟数**，Web 经 `SET_CFG` 写入，偏移 19；默认按 Web 选 5 / 10 min）。
- 倒计时期间主循环照常；`snooze_ticks` 每主循环 −1，**归零即重响同一闹钟一次**（`ring_alarm = snooze_idx; ring_ticks = 240; snooze_idx = 0`）。**每个贪睡只重响一次**；重响后仍不取消则静默结束（除非再次 `UP` 贪睡）。
- **贪睡倒计时期间按键不拦截、恢复常态功能**：`UP` 走正常"显示切换/轮回"、单击 `SET` 走"亮度调节"等，闹钟逻辑不接管；`snooze_ticks` 照常递减不被打断。若要提前取消待重响的贪睡，需等它**重响（再次 `ring_alarm` 置位）时按 `SET` 取消全部**。`snooze_idx` 为单槽，仅挂起一个待重响。
- 若贪睡挂起期间**另有闹钟到点响铃**：该响铃优先（`ring_alarm` 非零时贪睡倒计时暂停，响铃结束后续计），不会丢失挂起的贪睡、也不会提前触发；此时 `SET`/`UP` 对该新响铃生效。

### 7.5 与其他响铃的关系
- 与**事项提醒**（§十一）、**倒计时归零**（§五，8266 驱动 3 声）、**整点报时**（§八）共用同一蜂鸣器，触发与按键控制各自独立；闹钟 / 提醒的「贪睡 / 取消」逻辑相同（§十一 命中同此 7.2–7.4）。

## 八、整点报时（Web 开关，51 本地）

- Web 开关；开启后每逢整点蜂鸣器轻响 1–2 声提示，不打断。51 本地判定，无需网络。

## 九、关屏时段（Web 设置，51 本地）

- Web 设起止时分；51 每分钟比对，窗口内发 TM1639 关显命令（`0x80`）熄灭；窗口外恢复。
- 关屏期间单击任意键临时点亮 10s 便于查看（可选）。

## 十、时区与夏令时（Web 设置，ESP 换算）

- Web 设时区（如 UTC+8）与夏令时规则（预设：无 / 欧美自动）。
- ESP 在 `SET_TIME` 时按 tz+DST 把 UTC 换算成本地时间下推 51；51 存 `tz` 仅作显示/回显，不做 DST 计算。

## 十一、事项提醒（5 组）—— ⚠️ 51 端未实装，已裁撤

- **状态**：配置字段（`rem1–rem5`，54B 偏移 22–51）在 51 固件中**已定义、可经 `SET_CFG` 下推并 EEPROM 持久化**，但**分钟匹配逻辑未编写**——`main.c` 的整分比对只循环 3 个闹钟，**从不比对提醒**，故提醒**永远不会响**。
- **裁撤原因**：STC15W408AS Flash 仅 8KB（8192B）。闹钟/贪睡/整点报时等实装后固件达 **8152B（余 40B）**；实测补齐 5 组提醒的 4 类匹配（一次性/每周/每月/每年），即便用指针免乘法仍 **+197B → 8349B，超 157B**，装不进芯片。8KB 限制内无法落地，故放弃。
- 若未来需要：① 换更大 Flash 型号（硬件变更，当前设计已冻结，不采纳）；② 或显著削减功能（仅留"一次性+每周"且挪走其它特性腾 ROM）——均非当前范围。
- （保留原文设计作参考）每组可设四种重复类型：一次性（月/日/时/分，响一次）、每周（星期几 1–7+时/分）、每月（几号 1–31+时/分）、每年（月/日/时/分）。原定命中走 §七 同款响铃/贪睡/取消。

## 十二、WiFi / 伪待机 / 串口（原硬件，无唤醒线）

- 51 与 8266 仅 `TXD/RXD` 两根信号线，`RST`/`EN` 仅上拉、不连 51（硬件已冻结）。
- **伪待机（非真 sleep）**：8266 上电后 CPU 常驻运行、RF 关闭、AP 关闭、STA 断开；UART 始终有时钟、随时可收 51 指令。功耗约 15–18mA（CPU 跑、RF 关），市电可忽略。永不 deep-sleep，故「不会彻底死掉」。
- **STA 按需连接（不常驻）**：仅以下情况临时连 STA，关联后闲置 2 分钟自动断、回伪待机：① 上电校时；② 每日 `00:00`/`12:00` 自动对时；③ 51 发 `REQ_TIME`；④ **双击 `SET`（手动对时）**；⑤ 双键 ≥5s 重配网。
- **对时**：上电必对时；每日 `00:00`/`12:00` ESP 自定时对时（连 STA → NTP → 推 `SET_TIME` → 断 STA）；51 亦随时发 `REQ_TIME` 主动请求。
- **NTP 服务器（失败递进）**：固件内置列表，按顺序尝试直到成功——国内 3 个（`time1.aliyun.com`、`time2.aliyun.com`、`time3.aliyun.com`）+ 国外 2 个（`pool.ntp.org`、`time.google.com`）；某个不可用则连下一个，全部失败则维持 DS1302 走时并下次重试。
- **显示 IP（双击 SET）**：双击 `SET` 大屏显示 `P` + IP 末段（0–255）约 3s 并触发 8266 连 STA 做 NTP **对时**（手动校时）。IP 显示已简化——去掉原 4 段滚动与 `*26>>8` 除法，仅显 `P`+末段（省 ~115B）；完整 IP 由 8266 在 AP/STA 页展示（同网段直连）。
- **AP 配网模式（开 ⇔ STA 未连通）**：56dz AP 仅在「未配网 / 配网失败 / STA 掉线」时开启，**STA 一成功连通即关闭（配网一次性）**。每次上电先试连 STA：成功则 AP 关；失败则 AP 常开直到成功配网；配网失败自动恢复开启。双键 ≥5s 清凭据后 AP 重开。8266 后台持续重试 STA（指数退避），仅在连不上时保持 AP 开，避免瞬时掉线抖动。
- **LED_WIFI（蓝 LED，ESP GPIO2）+ ESP 自带 LED**：伪待机时全灭；**对时（含每日 00:00 / 12:00 自动对时、上电校时、双击 SET 手动对时）及开 AP 期间 RF 工作即点亮**，作工作指示。
- **双键 ≥5s**：51 发 `ENTER_AP(0x04)`，ESP 清 STA 凭据并恢复默认 AP 密码，重启进 AP 配网（热点 `56dz network clock`）。此功能保留：忘 AP 密码时唯一兜底。
- 配置权威在 51：ESP 上线 `REQ_CFG` 拉取，Web 改后 `SET_CFG` 回推 51 存 EEPROM。
  - **AP 密码（安全）**：配置 AP 默认带密码（出厂默认 `12345678`，建议贴于机身）；Web 内可修改 AP 密码；≥5s 重置会恢复默认 AP 密码，避免锁死。STA（所连 WiFi）密码同样在 Web 设。
  - **上电检测 8266 与调试模式**：上电监听 ~2s 等待 ESP 启动帧 `BOOT(0x8F)`（或任意合法帧）；收到即正常模式（8266 在线）。**超时未收到 → 蜂鸣器响 3 声，进入调试模式**：UART1 转作极详细日志（启动状态、EEPROM 配置 dump、DS1302 时间、ADC 光/温、按键、状态机；每字节 hex dump + 帧解析），并把串口收到的字节按 8266 协议帧解析（**人工用 PC 串口终端发数据模拟 8266**）。烧入真实 8266 固件即自动恢复正常模式。
    > ⚠️ 上述调试模式 very verbose 日志与 EEPROM 配置 dump **当前固件未实现**（仅 3 声蜂鸣；CODE 余量 8175/8192B（余 17B）不足以新增 dump 命令）。读已存配置改用 `REQ_CFG(0x87)`→`SET_CFG(0x82)`（`com_cfg.py`）。原始整片 EEPROM 读取不可行。

### Web 页面（两个，分开）
- **AP 配网页（连 `56dz network clock` 热点 → `192.168.4.1`）**：仅用于配网——输入路由器 / 手机热点的 WiFi 账号与密码，显示 STA 连接状态；配网成功（STA 连通）即自动关 AP 并提示「改用时钟 STA IP 访问配置页」。仅在未配网 / 重置时出现。
- **STA 配置页（8266 连上网后的同网段 IP）**：全功能设置（见 §十三）。**双击 `SET`** → 大屏显示 `P`+IP 末段 ~3s（完整 IP 见 8266 配置页）→ 同网段手机/电脑浏览器打开即配置页；8266 关联后闲置 2 分钟自动断 STA 回伪待机。
- 手机作热点时：8266 以 STA 连手机热点，手机在同网段直接浏览 STA IP；手机不能连 `56dz` AP，故首次配网用电脑连 `56dz` 填热点账号。

## 十三、STA 配置页清单（全功能，非 51 按钮项）

以下为 **STA 配置页**（连上网后通过同网段 IP 访问）可设项；**AP 配网页仅填 WiFi 账号**，不含下列：
  SMG1 选显(温度/日期)开关、**大屏整屏自动轮播开关（`display_mode`：0=固定 TIME / 1=每分钟轮换 TIME→DATE→TEMP）**、**红色状态灯使能开关（`led_en`：1=开 / 0=关，联网也不亮）**、**温度 °C/°F 切换（大屏整屏 TEMP 按 `cfg.temp_unit` 显 °C/°F；SMG1 温度恒°C）**、亮度（镜像）、3 组闹钟、温度参考标定、关屏时段、整点报时开关、贪睡时长、时区+夏令时、5 组事项提醒、**AP 密码（修改/重置）**、WiFi 账号改（改后重连）。改完回推 51 即时生效。

## 十四、断电保持

- CR1220 为 DS1302 备电，主电断仍走时；电池有字面正极朝上。倒计时预设时长存 EEPROM，断电不丢。

## 十五、硬件（已冻结）

- STC15W408AS 主控；TM1639；AMS1117-3.3 供 3.3V（MCU 直供 +5V）；SET/UP 两键；红 LED（LED_T=P1.2）；蓝 LED6（ESP GPIO2）。
- 硬件已冻结：51 与 8266 仅 `TXD/RXD` 互连，无唤醒线；8266 走「伪待机（CPU 常驻 RF 关）」模式，无需改板。

## 十六、操作速查（极简）

| 操作 | 功能 |
| --- | --- |
| 单击 SET | 亮度调节（闪显档位，UP 加减，再单击确认） |
| 长按 SET | 时间设置（UP 加，SET 移位/退出） |
| 长按 UP | 进入 / 退出计时器（V1 已实装） |
| 计时器内 单击 UP | 开始 / 停止（toggle 暂停/继续） |
| 计时器内 单击 SET | 复位归零（00:00） |

| 倒计时显示中 单击 SET | 发 `CD_CTRL(0x05)=0`：暂停/恢复（8266 执行） |
| 倒计时显示中 长按 SET | 发 `CD_CTRL(0x05)=1`：取消（8266 执行） |

| 贪睡倒计时中（未响铃） | 按键恢复常态功能（UP 显示切换 / SET 亮度），不被闹钟逻辑吞掉 |

## 十七、可选增强（已裁定）

- 事项短文本 SMG 滚动显示：**不做**（数码管显示内容已足够）。
- 多时区 / 世界时钟：**不做**。
- 温度 °C/°F 切换：**已纳入 §十三 STA 配置页**（Web 设，51 据 `temp_unit` 渲染数码管）。

## 十八、容量取舍（8KB Flash 已用尽说明）

51 固件 CODE 上限 **8192B（8KB）**，当前实测占用 **~8175B（0x1FEE，余 ~17B）**。下列取舍均为「塞进 8KB」所迫，非功能设计本意：

- **倒计时移 8266**：51 不再维护倒计时 tick 与设定态，仅显示 8266 每 1s 推送的 `MM:SS` 并转发设备键（省 ~203B）。时长设定/记忆交给 8266 Web。
- **IP 显示简化**：双击 SET 大屏显示 `P`+IP 末段（0–255）~3s（去掉原 4 段滚动与 `*26>>8` 除法，省 ~115B）；完整 IP 改由 8266 Web 配置页展示。手动对时照常。
- **计时器封顶 `99:59`**：原 `99:59:59` 的「时」位被裁，免去小时进位与显存（与倒计时统一为 `MM:SS`，复用 `put_mmss`）。
- **`cd_preset` 字段保留但不消费**：为不改动 `SET_CFG` 54B 帧长（8266 解析不受影响），51 不再读写该字节。
- **禁止引入 `__mulint` 库**：`display.c` 的 `abs_div10` 曾用 `a*26>>8` 近似 |v|/10，拉入 44B 的 `__mulint` 例程；后改为 16 位 `a/10` 减法循环剔除此库（CODE 8189→8175）。任何 16 位乘法/除法一律用移位或减法循环替代，避免重拉该库。
- 计时器（51 原生）与倒计时显示接管（P2 方案）已实装；若后续需恢复某项被裁能力，须先裁掉等量的其它特性或换更大 Flash 型号（如 STC15W4K）。
