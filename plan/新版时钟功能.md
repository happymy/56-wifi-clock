# 新版 WiFi 时钟功能规格（v2，极简版）

> 基于 `doc/原版时钟功能.md` 复刻并扩展。硬件：STC15W408AS（1T 8051）+ TM1639 数码管 + DS1302 实时时钟 + ESP-01S（ESP8266，自写固件，Web 配网/校时）。
> **设计原则**：51 端按键只保留最常用、必须的功能（手动对时、亮度、计时器、倒计时、重配网）；其余设置全部放 8266 Web。界面简单、直觉、人性化。
> 配置权威在 51（EEPROM）；8266 上线拉取、Web 修改后回推。串口协议见 `plan/串口通信协议.md`。

## 一、显示与轮显

- 上电默认时钟：大数码管 `HH:MM` + SMG2 `SS`（秒）+ SMG1（温度或日期片段）。
- **长按 `UP`**：时钟 ↔ 计时器 切换（计时器见 §四）。**双击 `UP`**：时钟 ↔ 倒计时 切换（见 §五）。
- **自动轮显**（Web 开关）：循环 时间 / 日期 / 温度；轮显项由 Web「温度轮显」「日期轮显」勾选。
- **日期显示**：大屏 `MMDD`（月日），**SMG2 末位小数点点亮**作日期标识；SMG1 可显星期或空。

## 二、亮度调节（51 按钮，Web 亦可）

- **单击 `SET`** 进入亮度调节：数码管闪显档位，`UP` 加减（0=自动光敏，1–8=手动），再次 **单击 `SET`** 确认退出。
- 自动档叠加极暗软件 PWM（≈1/1024，不灭不闪）。Web 端可镜像设置。

## 三、手动时间设置

- **长按 `SET`** 进入时间设置：依次 时→分→秒→年→月→日 闪烁，`UP` 加一，单击 `SET` 移位，退出即写入 DS1302。
- 联网后 ESP 唤醒时顺带 NTP 校时（`SET_TIME`，已含时区/夏令时换算），无需手动对时也能准。

## 四、计时器（51 原生，秒精度）

- **长按 `UP`** 进入/退出计时器模式。
- **单击 `UP`**：开始 / 停止（toggle）。**单击 `SET`**：复位归零。
- 显示：大数码管 `HH:MM`，**SMG1 显 `SS`（0–59），SMG2 不显示**。时基复用 T0 相位计数器派生的 1s tick。上限 `99:59:59`。

## 五、倒计时（51 原生，自动记忆时长）

- **双击 `UP`** 进入/退出倒计时模式。
- 进入后大屏显示**上次记忆的时长** `MM:SS`（默认 `05:00`）。
- 未运行时 **单击 `SET`** 在预设档 `[1, 3, 5, 10, 15, 30, 60]` 分间切换；选定时长存 EEPROM，**下次进入沿用（自动记忆）**。
- **单击 `UP`**：开始 / 暂停。运行中大屏显剩余 `MM:SS`。
- 归零：蜂鸣器响（30s 渐强，贪睡/关闭同闹钟 §七）。
- 显示细节：大屏 `MM:SS` 剩余；SMG1 可显设定总秒末两位或空，SMG2 空白（保持与计时器一致风格）。

## 六、温度与补偿（8266 Web 参考温度标定）

- 51 读 NTC（RM1, P1.1）算原始温度并显示。
- **补偿 = 参考温度单点标定**：Web 输入正整数「参考温度」（如 24，即你用靠谱温度计测得的真值）；51 收到 `SET_CFG` 时读当前 NTC 原始值 `T0`，存 `offset = 参考 − T0`（有符号）。
- 之后任意时刻 `显示温度 = NTC原始 + offset`，全程线性跟随、自适应漂移，精度取决于 NTC 分辨率（优于手工 ±8 固定偏移）。
- **51 不提供手动补偿菜单**。

## 七、闹钟（3 组，Web 设置；51 响铃）

- 三组独立闹钟（开关+时+分）经 8266 Web 设置，51 存 EEPROM 并应用。
- 响铃：蜂鸣器，**持续 30s，音量由低到高渐强（约 3–5s 升至峰值）**。
- 响铃中 **单击 `UP` = 贪睡**（默认 5/10 min，Web 选），**单击 `SET` = 关闭**。

## 八、整点报时（Web 开关，51 本地）

- Web 开关；开启后每逢整点蜂鸣器轻响 1–2 声提示，不打断。51 本地判定，无需网络。

## 九、关屏时段（Web 设置，51 本地）

- Web 设起止时分；51 每分钟比对，窗口内发 TM1639 关显命令（`0x80`）熄灭；窗口外恢复。
- 关屏期间单击任意键临时点亮 10s 便于查看（可选）。

## 十、时区与夏令时（Web 设置，ESP 换算）

- Web 设时区（如 UTC+8）与夏令时规则（预设：无 / 欧美自动）。
- ESP 在 `SET_TIME` 时按 tz+DST 把 UTC 换算成本地时间下推 51；51 存 `tz` 仅作显示/回显，不做 DST 计算。

## 十一、事项提醒（5 组，Web 设置；51 响铃）

- 每组可设三种重复类型（参考常见提醒类应用，优化为最常用三型）：
  - **一次性**：指定 月/日/时/分，到点响一次。
  - **每周**：指定 星期几（1–7）+ 时/分，每周重复。
  - **每月**：指定 几号（1–31）+ 时/分，每月重复。
- 51 每分钟比对启用的提醒；命中则响铃（同 §七：30s 渐强，贪睡/关闭同上）。
- 可选增强：响铃时 SMG 滚动显示事项短名（未来，需 8266 额外下发文本）。

## 十二、WiFi / 低功耗 / 串口（原硬件，无唤醒线）

- 51 与 8266 仅 `TXD/RXD` 两根信号线，`RST`/`EN` 仅上拉、不连 51（硬件已冻结）。
- **休眠 = light-sleep（RF 关、RTC 开，约 0.8mA）**：空闲超时进 light-sleep，AP/STA 均不可用；51 由 +5V 直供独立运行（显示/走时/按键不受影响）。
- **唤醒（UART，无需飞线）**：51 发任意 UART 帧（如 `REQ_TIME`）即由起始位唤醒 → ESP 开 RF、NTP 校时、开 AP+Web 窗口（默认 5 min 空闲回 sleep）。
- **LED_WIFI（蓝 LED，ESP GPIO2）**：只要 8266 工作（唤醒/RF 开）即点亮，light-sleep 时熄灭，作工作指示（51 不可控/不可测）。
- **双键 2–10s**：51 发 `REQ_TIME` 唤醒 ESP + 同步 + 开 AP/Web。
- **双键 ≥10s**：51 发 `ENTER_AP`，ESP 清 STA 凭据并恢复默认 AP 密码，重启进 AP 配网。
- 配置权威在 51：ESP 上线 `REQ_CFG` 拉取，Web 改后 `SET_CFG` 回推 51 存 EEPROM。
- **AP 可用性**：AP 仅在 8266 唤醒（RF 开）期间可用——即按钮唤醒窗口内，或初始/重置后的配网期。故「配置前先按双键 2–10s 唤醒」。可选「常开模式」Web 开关：开启后 AP+STA 常驻不休眠（功耗高，换来随时可达）。
- **AP 密码（安全）**：配置 AP 默认带密码（出厂默认 `12345678`，建议贴于机身）；Web 内可修改 AP 密码；≥10s 重置会恢复默认 AP 密码，避免锁死。STA（所连 WiFi）密码同样在 Web 设。

### Web 访问方式
- 配网/配置：按双键 2–10s 唤醒 → 连 `56dz network clock` 热点（输 AP 密码）→ 浏览器 `192.168.4.1`。唤醒窗口结束自动 sleep，AP 关闭。
- 初始/重置后 ESP 自动进 AP 配网模式，AP 可用直到配网完成。
- **若 8266 连手机热点（手机作 AP）**：手机自身无法再连 `56dz` AP。此时 8266 以 STA 获手机分配 IP，可由 51 把该 IP 滚显在数码管上（命令 `0x88 STA_IP`）供手机浏览器输入；或 mDNS `clock.local`（iOS 支持）。建议配网优先用家庭路由器；便携手机热点场景用电脑连 `56dz` AP 配置，或读时钟滚显 IP。

## 十三、Web 配置清单（全部非 51 按钮项）

ESP 网页可设：温度轮显开关、日期轮显开关、亮度（镜像）、3 组闹钟、温度参考标定、关屏时段、整点报时开关、贪睡时长、时区+夏令时、5 组事项提醒、**AP 密码（修改/重置）**、**常开模式开关**。改完回推 51 即时生效。

## 十四、断电保持

- CR1220 为 DS1302 备电，主电断仍走时；电池有字面正极朝上。倒计时预设时长存 EEPROM，断电不丢。

## 十五、硬件（已冻结）

- STC15W408AS 主控；TM1639；AMS1117-3.3 供 3.3V（MCU 直供 +5V）；SET/UP 两键；红 LED（LED_T=P1.2）；蓝 LED6（ESP GPIO2）。
- 硬件已冻结：51 与 8266 仅 `TXD/RXD` 互连，唤醒靠 UART light-sleep 唤醒，无需改板。

## 十六、操作速查（极简）

| 操作 | 功能 |
| --- | --- |
| 单击 SET | 亮度调节（闪显档位，UP 加减，再单击确认） |
| 长按 SET | 时间设置（UP 加，SET 移位/退出） |
| 长按 UP | 进入 / 退出计时器 |
| 计时器内 单击 UP | 开始 / 停止 |
| 计时器内 单击 SET | 复位归零 |
| 双击 UP | 进入 / 退出倒计时 |
| 倒计时内 单击 SET | 切换预设时长（EEPROM 记忆） |
| 倒计时内 单击 UP | 开始 / 暂停 |
| 双键 2–10s | 唤醒 ESP + 同步 + 开 Web |
| 双键 ≥10s | 重新配网（AP） |
| 闹钟/提醒/倒计时响 单击 UP | 贪睡 |
| 闹钟/提醒/倒计时响 单击 SET | 关闭 |
