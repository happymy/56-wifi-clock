# 51 ↔ ESP8266 串口通信协议

> 范围：STC15W408AS（51 侧）与 ESP-01S（ESP8266，自写固件）之间的自定义 UART 协议。
> 用途：NTP 时间同步、Web 配置下发/拉取、网络状态上报、重新配网触发。
> 重要前提：**配置权威在 51（EEPROM）**；8266 上线后向 51 拉取配置，Web 修改后回推 51。
> 物理层：UART1，`P3.0(RXD)←ESP TXD`、`P3.1(TXD)→ESP RXD`；**9600 8N1**（11.051MHz 下 Timer2 波特源已验证）。全双工链路，帧级半双工握手。

## 1. 帧格式

```
[SYNC0][SYNC1][CMD][LEN][PAYLOAD...][CHK]
```

- `SYNC0=0xAA`, `SYNC1=0x55`：帧头；接收方未对齐时持续丢弃直到匹配。
- `CMD`：1 字节命令（§3）。
- `LEN`：1 字节，PAYLOAD 字节数（0–255）。
- `PAYLOAD`：LEN 字节（§5 为定长配置结构）。
- `CHK`：1 字节 = `XOR(CMD, LEN, PAYLOAD[0..LEN-1])`；不符则丢弃并回 `NAK`。

## 2. 时序与流控

- 无硬件流控。
- 51 侧：UART1 接收用中断 + 环形缓冲；发送用 `uart_send()` 阻塞。
- 帧间间隔 ≥5ms，避免 51 接收溢出。
- **伪待机 UART 始终在线**：ESP 伪待机为 CPU 常驻、RF 关，UART 外设始终有时钟；51 发任意帧均被正常接收，无唤醒延迟、无首字节丢失，无需唤醒脉冲/延时。直接发帧、等应答即可。
- 请求/应答：发请求帧后等应答，超时 1s 重发（最多 3 次），失败则维持原状态、继续用 DS1302 走时。
- ESP 主动下发（Web 改配置）无需 51 先请求，51 收即应用并回 `ACK`。

## 3. 命令表

### MCU → ESP

| CMD | 名称 | PAYLOAD | 说明 |
| --- | --- | --- | --- |
| `0x01` | REQ_TIME | 无 | 请求 NTP 时间（含时区），ESP 回 `0x81` |
| `0x02` | HEARTBEAT | 无 | 在线心跳，ESP 回 `0x83` NET_STATUS |
| `0x03` | BTN_EVENT | 1B 事件码（§4） | 上报按键事件（供 Web 显示），可选 |
| `0x04` | ENTER_AP | 无 | 双键 ≥10s 触发：清 STA 凭据 + 恢复默认 AP 密码，重启进 AP 配网（热点 `56dz network clock`） |
| `0x82` | SET_CFG | 54B（§5） | **51→ESP**：应答 `REQ_CFG`，下发 51 当前配置供 Web 展示 |

### ESP → MCU

| CMD | 名称 | PAYLOAD | 说明 |
| --- | --- | --- | --- |
| `0x81` | SET_TIME | 7B BCD：年(0–99) 月 日 星期 时 分 秒 + 1B 时区(有符号) | 写入 DS1302（ESP 已换算本地时间含 DST） |
| `0x82` | SET_CFG | 54B（§5） | **ESP→51**：Web 改配置后回推 51 存 EEPROM 并应用 |
| `0x83` | NET_STATUS | 1B：0=未连 1=连接中 2=已连 3=已同步 | 网络/同步状态 |
| `0x84` | AP_READY | 无 | ESP 已进入 AP 配网（热点 `56dz network clock`） |
| `0x85` | ACK | 1B：原 CMD | 校验通过确认 |
| `0x86` | NAK | 1B：原 CMD | 校验失败/未知命令，请求重发 |
| `0x87` | REQ_CFG | 无 | ESP→51：上线后拉取 51 当前配置（51 回 `0x82` SET_CFG） |
| `0x88` | STA_IP | 4B | ESP STA 获取到的 IPv4（手机热点等场景供 51 滚显，便于手机浏览器访问） |
| `0x8F` | BOOT | 0/1B 版本(可选) | ESP 固件启动完成、UART 就绪后**主动上报**（上电尽早发）；51 据此判定 8266 在线（见 §9 调试模式）。 |

> 注：`0x82 SET_CFG` 同一命令双向复用——方向由发送方决定：51 发=配置下行（应答拉取），ESP 发=配置上行（Web 改后存回）。接收方据此更新。

## 4. 按键事件码（BTN_EVENT，可选）

| 码 | 含义 |
| --- | --- |
| `0x01` | 单击 SET（亮度调节） |
| `0x02` | 单击 UP |
| `0x03` | 双击 SET（显示 IP + 手动对时） |
| `0x04` | 长按 SET（进入时间设置，纯 51 逻辑） |
| `0x05` | 长按 UP（计时器，纯 51 逻辑） |
| `0x06` | 双击 UP（进入/退出倒计时，纯 51 逻辑） |
| `0x08` | 双键 ≥10s（重配网） |

> 双击 UP 进入/退出倒计时（51 原生，时长 EEPROM 记忆）。

| 28 | rem2 | 6B | Web | 事项提醒② |

| 40 | rem4 | 6B | Web | 事项提醒④ |
| 46 | rem5 | 6B | Web | 事项提醒⑤ |
| 52 | cd_preset | 1B | 51/Web | 倒计时预设时长（分钟 1–60，默认 5；51 双击 UP 进入时切换并记忆） |

合计 54B，`LEN=54`。**51 本地仅改 `bright_mode/bright_lvl`、倒计时 `cd_preset` 与时间（DS1302 非本结构）；其余字段仅由 8266 Web 写入并经 `SET_CFG` 下推。**

### 6.1 事项提醒结构（每组 6B）

| 字节 | 含义 |
| --- | --- |
| 0 | enable（0/1） |
| 1 | type（0=一次性 1=每周 2=每月 3=每年） |
| 2 | 一次性：月(1–12)；每周：星期几(1–7)；每月：0；每年：月(1–12) |
| 3 | 一次性：日(1–31)；每周：0；每月：日(1–31)；每年：日(1–31) |
| 4 | 时(0–23) |
| 5 | 分(0–59) |

51 每分钟比对启用的提醒：一次性按 月+日+时+分；每周按 星期几+时+分；每月按 日+时+分；每年按 月+日+时+分。命中响铃（同闹钟 30s 渐强）。

## 6. 伪待机与唤醒（CPU 常驻 RF 关，原硬件无唤醒线）

- 原硬件：51 与 ESP 仅 `TXD/RXD` 互连，`RST`/`EN` 仅上拉未连 51（硬件已冻结），无 GPIO 唤醒线。
- **伪待机（非真 sleep）**：8266 上电即进伪待机——CPU 常驻运行、RF 关闭、AP 关、STA 断；UART 始终有时钟、随时可收 51 指令。功耗约 15–18mA（CPU 跑、RF 关），市电可忽略。永不 deep-sleep。
- **STA 按需连接（不常驻）**：仅 ①上电校时 ②每日 `00:00`/`12:00` 自动对时 ③51 `REQ_TIME` ④双击 SET（显示 IP+手动对时）⑤双键 ≥10s 重配网 时临时连 STA；关联后闲置 2 分钟自动断 STA 回伪待机。
- **对时**：上电必对时；内部软件定时器每日 `00:00`、`12:00` 触发——临时连 STA → NTP → 推 `SET_TIME` → 断 STA 回伪待机。51 亦随时发 `REQ_TIME` 主动请求。
- **NTP 服务器（失败递进）**：固件内置列表，按顺序尝试直到成功——国内 3 个（`time1.aliyun.com`、`time2.aliyun.com`、`time3.aliyun.com`）+ 国外 2 个（`pool.ntp.org`、`time.google.com`）；某台不可用连下一台，全失败则维持 DS1302 走时、下次再试。
- **显示 IP（双击 SET）**：8266 关联后回 `STA_IP(0x88)`，51 滚显其 IP 10 秒；该键同时触发 NTP 对时（显示 IP + 手动对时合一）。配置页即在此 IP（同网段直连）。
- **AP 配网模式（开 ⇔ STA 未连通）**：56dz AP 仅在「未配网 / 配网失败 / STA 掉线」时开，**STA 一连通即关（配网一次性）**。上电先试连 STA：成功则 AP 关；失败则 AP 常开直到成功配网；配网失败自动恢复开。双键 ≥10s 清凭据后 AP 重开。8266 后台重试 STA（指数退避），仅连不上时保持 AP 开。
- **Web 两页分离**：① **AP 配网页**（`56dz network clock` → `192.168.4.1`）仅填 WiFi 账号、显 STA 状态，配网成功即关 AP；② **STA 配置页**（8266 连上网后的同网段 IP）全功能设置，双击 SET 显示此 IP 供访问。
- **LED_WIFI（ESP GPIO2 蓝）+ ESP 自带 LED**：伪待机全灭；仅 RF 工作（对时 / 开 AP）时点亮。
- **AP 密码（安全）**：配置 AP 默认带密码（出厂 `12345678`，建议贴机身）；Web 可改；≥10s 重置恢复默认 AP 密码，避免锁死。AP 密码存 ESP flash，不进 51 的 54B 配置结构。
- **重配网**：51 发 `ENTER_AP(0x04)`，ESP 清 STA 凭据并恢复默认 AP 密码，重启进 AP 配网（热点 `56dz network clock`，Web `192.168.4.1`），回 `AP_READY(0x84)`。
- 备选 deep-sleep 更省电但只能 RTC 定时自醒、51 无法按需触发，且 ESP-01S 未连 `XPD_DCDC→EXT_RSTB` 定时唤醒不可用——故选伪待机。

## 7. 重新配网（双键 ≥10s）

- 51 检测 `UP+SET` 同按 ≥10s → 发 `ENTER_AP(0x04)`；ESP 清凭据、恢复默认 AP 密码、重启进 AP 模式（热点 `56dz network clock`，Web `192.168.4.1`），回 `AP_READY(0x84)`。
- 配置完成 ESP 自动重连并恢复 `SET_TIME` 校时。

## 8. 上电流程

1. 51 上电初始化 → 读 DS1302（CH 位判定走时）→ **进入 8266 握手窗口（~2s）监听 `BOOT(0x8F)` 或任意合法帧**：收到则正常模式（8266 在线）；超时未收到则蜂鸣器响 3 声、进入**调试模式**（UART1 详细日志 + 接收模拟 8266 数据，见 §9）。
2. ESP 上电即试连 STA 校时（连 STA → NTP → `SET_TIME`）；**同时据配网状态决定 AP**：STA 连通则 AP 关，未连通则开 AP 配网（热点 `56dz network clock`，Web `192.168.4.1`）待用户填 WiFi 账号，配网成功即关 AP。ESP 固件启动刚完成即发 `BOOT(0x8F)` 让 51 尽早判定在线。
3. 配网成功 ESP 上线 → `REQ_CFG` 向 51 拉配置（51 回 `0x82`）。
4. 此后每日 00:00 / 12:00 ESP 自定时对时（临时连 STA 后断）；亦随时 `REQ_TIME` 主动请求；双击 SET 显示 IP + 手动对时。STA 关联闲置 2 分钟自动断；AP 开 ⇔ STA 未连通，连通即关。

## 9. 上电检测与调试模式（8266 缺失时调试 51）

- **握手窗口**：51 上电后开启 ~2s 监听 UART，期待收到合法帧，尤其 ESP 上电主动发的 `BOOT(0x8F)`（SYNC+CMD+CHK 通过即算合法）。
- **判定**：窗口内收到任意合法帧 → 8266 在线，进入正常模式；窗口超时无任何合法帧 → 判定 8266 未连接/未启动。
- **调试模式（未检测到 8266）**：蜂鸣器响 3 声进入该模式。行为：
  - UART1 专作**极详细日志（very verbose）**：启动状态、EEPROM 配置全 dump（54B hex）、DS1302 时间、ADC 光/温原始值、按键事件、状态机迁移；UART 收发的**每字节 hex dump** 与解析后的帧（CMD/LEN/PAYLOAD/CHK）。
  - 串口收到的字节按本协议帧解析，等同真实 8266 下发——**人工用 PC 串口终端发数据即可模拟 8266**（如手动发 `SET_TIME`/`SET_CFG`/`NET_STATUS`/`STA_IP` 驱动 51 逻辑）。
  - 此模式不连真实 8266，故可安全全量打印，不影响任何链路。
- 烧入真实 8266 固件后上电检测到 `BOOT(0x8F)` → 自动正常模式，调试打印关闭。
- **正常模式严禁任何串口调试打印**（日志走 EEPROM 环形区，见 `固件复刻计划.md` §14）。调试模式仅在 8266 缺失（或 `g_cfg.debug_uart=1` 强制）时启用。
