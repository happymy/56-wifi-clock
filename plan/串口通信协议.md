# 51 ↔ ESP8266 串口通信协议

> 范围：STC15W408AS（51 侧）与 ESP-01S（ESP8266，自写固件）之间的自定义 UART 协议。
> 用途：NTP 时间同步、Web 配置下发/拉取、网络状态上报、重新配网触发。
> 重要前提：**配置权威在 51（EEPROM）**；8266 上线后向 51 拉取配置，Web 修改后回推 51。
> 物理层：UART1，`P3.0(RXD)←ESP TXD`、`P3.1(TXD)→ESP RXD`；**9600 8N1**（11.051MHz 下 Timer2 波特源已验证）。全双工链路，帧级半双工握手。

## 1. 帧格式

```
[SYNC0][SYNC1][CMD][LEN][PAYLOAD...][CHK]
```

- `SYNC0=0xAA`, `SYNC1=0x55`：帧头；接收方未对齐时持续丢弃直到匹配。
- `CMD`：1 字节命令（§3）。
- `LEN`：1 字节，PAYLOAD 字节数（0–255）。
- `PAYLOAD`：LEN 字节（§5 为定长配置结构）。
- `CHK`：1 字节 = `XOR(CMD, LEN, PAYLOAD[0..LEN-1])`；不符则丢弃并回 `NAK`。

## 2. 时序与流控

- 无硬件流控。
- 51 侧：UART1 接收用中断 + 环形缓冲；发送用 `uart_send()` 阻塞。
- 帧间间隔 ≥5ms，避免 51 接收溢出。
- **唤醒帧**：ESP 在 light-sleep 时 RF 关闭，51 发送任意帧的起始位即唤醒；建议 51 唤醒时先发 `0x01 REQ_TIME`（既唤醒又请求校时），发后延时 ~50ms 再期待应答。
- 请求/应答：发请求帧后等应答，超时 1s 重发（最多 3 次），失败则维持原状态、继续用 DS1302 走时。
- ESP 主动下发（Web 改配置）无需 51 先请求，51 收即应用并回 `ACK`。

## 3. 命令表

### MCU → ESP

| CMD | 名称 | PAYLOAD | 说明 |
| --- | --- | --- | --- |
| `0x01` | REQ_TIME | 无 | 请求 NTP 时间（含时区），ESP 回 `0x81` |
| `0x02` | HEARTBEAT | 无 | 在线心跳，ESP 回 `0x83` NET_STATUS |
| `0x03` | BTN_EVENT | 1B 事件码（§4） | 上报按键事件（供 Web 显示），可选 |
| `0x04` | ENTER_AP | 无 | 请求 8266 清凭据并进 AP 配网（双键 ≥10s 触发） |
| `0x82` | SET_CFG | 20B（§5） | **51→ESP**：应答 `REQ_CFG`，下发 51 当前配置供 Web 展示 |

### ESP → MCU

| CMD | 名称 | PAYLOAD | 说明 |
| --- | --- | --- | --- |
| `0x81` | SET_TIME | 7B BCD：年(0–99) 月 日 星期 时 分 秒 + 1B 时区(有符号) | 写入 DS1302（ESP 已换算本地时间含 DST） |
| `0x82` | SET_CFG | 53B（§5） | **ESP→51**：Web 改配置后回推 51 存 EEPROM 并应用 |
| `0x83` | NET_STATUS | 1B：0=未连 1=连接中 2=已连 3=已同步 | 网络/同步状态 |
| `0x84` | AP_READY | 无 | ESP 已进入 AP 配网（热点 `56dz network clock`） |
| `0x85` | ACK | 1B：原 CMD | 校验通过确认 |
| `0x86` | NAK | 1B：原 CMD | 校验失败/未知命令，请求重发 |
| `0x87` | REQ_CFG | 无 | ESP→51：上线后拉取 51 当前配置（51 回 `0x82` SET_CFG） |
| `0x88` | STA_IP | 4B | ESP STA 获取到的 IPv4（手机热点等场景供 51 滚显，便于手机浏览器访问） |

> 注：`0x82 SET_CFG` 同一命令双向复用——方向由发送方决定：51 发=配置下行（应答拉取），ESP 发=配置上行（Web 改后存回）。接收方据此更新。

## 4. 按键事件码（BTN_EVENT，可选）

| 码 | 含义 |
| --- | --- |
| `0x01` | 单击 SET（亮度调节） |
| `0x02` | 单击 UP |
| `0x03` | 双击 SET |
| `0x04` | 长按 SET（时间设置） |
| `0x05` | 长按 UP（进入/退出计时器） |
| `0x06` | 双击 UP（进入/退出倒计时） |
| `0x07` | 双键 2–10s（唤醒+同步） |
| `0x08` | 双键 ≥10s（重配网） |

> 双击 UP 进入/退出倒计时（51 原生，时长 EEPROM 记忆）。

## 5. 配置结构（SET_CFG PAYLOAD，定长 53B）

| 偏移 | 字段 | 长度 | owner | 说明 |
| --- | --- | --- | --- | --- |
| 0 | display_mode | 1B | Web | 0=固定(仅时间) 1=自动轮显 |
| 1 | bright_mode | 1B | 51/Web | 0=自动(光敏) 1=手动（51 单击 SET 改，Web 可镜像） |
| 2 | bright_lvl | 1B | 51/Web | 手动亮度档 1–8 |
| 3 | temp_offset | 1B | Web(算) | 有符号温度补偿，由 8266 在用户填「参考温度」正整数时按 `参考−当前NTC` 算出下推；51 透明应用 |
| 4 | alarm1 | 3B | Web | on(0/1) + 时 + 分 |
| 7 | alarm2 | 3B | Web | on + 时 + 分 |
| 10 | alarm3 | 3B | Web | on + 时 + 分 |
| 13 | tz | 1B | Web | 时区（有符号，UTC+8=+8） |
| 14 | off_start | 2B | Web | 关屏时段起 时+分（`0xFF`=禁用） |
| 16 | off_end | 2B | Web | 关屏时段止 时+分 |
| 18 | chime | 1B | Web | 整点报时 0=关 1=开（2=半点也报） |
| 19 | snooze | 1B | Web | 贪睡 0=关 5/10=贪睡分钟数 |
| 20 | dst | 1B | Web | 夏令时规则 0=无 1=欧美自动 … |
| 21 | cycle_flags | 1B | Web | bit0=温度轮显 bit1=日期轮显（display_mode=1 时生效） |
| 22 | rem1 | 6B | Web | 事项提醒①（§6 结构） |
| 28 | rem2 | 6B | Web | 事项提醒② |
| 34 | rem3 | 6B | Web | 事项提醒③ |
| 40 | rem4 | 6B | Web | 事项提醒④ |
| 46 | rem5 | 6B | Web | 事项提醒⑤ |
| 52 | cd_preset | 1B | 51/Web | 倒计时预设时长（分钟 1–60，默认 5；51 双击 UP 进入时切换并记忆） |

合计 53B，`LEN=53`。**51 本地仅改 `bright_mode/bright_lvl`、倒计时 `cd_preset` 与时间（DS1302 非本结构）；其余字段仅由 8266 Web 写入并经 `SET_CFG` 下推。**

### 6.1 事项提醒结构（每组 6B）

| 字节 | 含义 |
| --- | --- |
| 0 | enable（0/1） |
| 1 | type（0=一次性 1=每周 2=每月） |
| 2 | 一次性：月(1–12)；每周：星期几(1–7)；每月：0 |
| 3 | 一次性：日(1–31)；每周：0；每月：日(1–31) |
| 4 | 时(0–23) |
| 5 | 分(0–59) |

51 每分钟比对启用的提醒：一次性按 月+日+时+分；每周按 星期几+时+分；每月按 日+时+分。命中响铃（同闹钟 30s 渐强）。

## 6. 低功耗与唤醒（light-sleep + UART 唤醒，原硬件无唤醒线）

- 原硬件：51 与 ESP 仅 `TXD/RXD` 互连，`RST`/`EN` 仅上拉未连 51（硬件已冻结），故 **51 不能用 GPIO 唤醒 ESP**。
- ESP 运行 **AP+STA**：始终自开 AP `56dz network clock`（IP `192.168.4.1`）供配置；同时 STA 连用户 WiFi/手机热点取 NTP。
- **休眠 = light-sleep**（RF 关、RTC 开，约 0.8mA）：空闲超时进 light-sleep；51 由 +5V 直供独立运行。
- **唤醒（UART，无需飞线）**：ESP light-sleep 可被 UART 起始位唤醒。51 向 ESP 发任意帧（如 `0x01 REQ_TIME`）即唤醒 → ESP 开 RF、NTP 校时、开 Web 窗口，空闲超时回 light-sleep（手动同步，DS1302 守时无需连续同步）。
- **重配网**：51 发 `ENTER_AP(0x04)`，ESP 清凭据重启进 AP 配网（热点 `56dz network clock`）。
- 备选：若需更低功耗可用 deep-sleep，但唤醒只能靠 ESP 内部 RTC 定时器（定期自醒），51 无法按需触发——故默认选 light-sleep。

## 7. 重新配网（双键 ≥10s）

- 51 检测 `UP+SET` 同按 ≥10s → 发 `ENTER_AP(0x04)`；ESP 清凭据、重启进 AP 模式（热点 `56dz network clock` / `56dz.com`，Web `192.168.4.1`），回 `AP_READY(0x84)`。
- 配置完成 ESP 自动重连并恢复 `SET_TIME` 校时。

## 8. 上电流程

1. 51 上电初始化 → 读 DS1302（CH 位判定走时）。
2. ESP 若本地无凭据 → 自启 AP；51 周期性 `REQ_TIME`，AP 模式下 ESP 不回时间。
3. 配网成功 ESP 上线 → `REQ_CFG` 向 51 拉配置（51 回 `0x82`）；ESP 顺带 `SET_TIME` 校时（或 51 `REQ_TIME`）。
4. 此后仅在唤醒/配网时校时，无连续轮询（省电）。
