## 2. 数码管驱动芯片 (U2: TM1639)

> TM1639（Titan Micro）标准封装为 **SOP24 / SDIP24（24 脚）**，显示模式 8 段×8 位、键扫 4×2bit（仅 K0/K1 两路），与 TM1638 的 SOP28 不同。原表虽为 24 脚，但 GRID 顺序与 SEG 编号错乱（SEG2–SEG5 缺失，实为 SEG9–SEG12）。以下按官方数据手册 24 脚引脚定义重写：段输出为 SEG1–SEG4（复用 KS1–KS4，引脚 12–15）与 SEG9–SEG12（引脚 16–19），逻辑段 SEG5–SEG8 对应物理 SEG9–SEG12；GRID1–GRID8 分布于引脚 1/2/4/5/20/21/23/24。

| 引脚号 | 引脚名称 | 连接网络 / 功能说明 |
| ---: | --- | --- |
| 1 | GRID4 | GRID4（主屏第 4 位位选） |
| 2 | GRID3 | GRID3（主屏第 3 位位选，物理倒装 180°） |
| 4 | GRID2 | GRID2（主屏第 2 位位选） |
| 5 | GRID1 | GRID1（LED2 公共端，经限流电阻接位选） |

### 4.3 GRID 与数码管位对应关系

TM1639 的 8 个位选 GRID1–GRID8 分别驱动三块显示：主屏 4 位（GRID1–4）、SMG1 两位（GRID5/6）、SMG2 两位（GRID7/8）。固件中 `disp[0..7]` 依次对应 GRID1..GRID8。

| GRID | 数码管 | 位（左 / 右） | 显示内容 | 备注 |
| ---: | --- | --- | --- | --- |
| GRID1 | 主屏 | 第 1 位（LED2，FJ12101AH 单一位） | 主显最高位 | |
| GRID2 | 主屏 | 第 2 位 | | |
| GRID3 | 主屏 | 第 3 位 | | **物理倒装 180°**，段码写入前需 `seg_rotate180` |
| GRID4 | 主屏 | 第 4 位 | | |
| GRID5 | SMG1 | 右位 | 个位 | 顶部引脚 7 |
| GRID6 | SMG1 | 左位 | 十位 | 顶部引脚 8 |
| GRID7 | SMG2 | 右位 | 个位 | |
| GRID8 | SMG2 | 左位 | 十位 | |

> SMG1/SMG2 的左右位与 GRID 对应关系见上表。固件写 `disp[4..5]`（SMG1）与 `disp[6..7]`（SMG2）时，将十位送左管（GRID6 / GRID8）、个位送右管（GRID5 / GRID7），故显示方向为左=十位、右=个位（即正常的“十位在左、个位在右”阅读顺序）。详见 `固件复刻计划.md` §3 显示驱动与 `demo/hw-test/src/main.c` 的 `disp_step`/`disp_hilo`。

## 6. WiFi 模块 (U11: ESP-01 / ESP-01S)

> 原表引脚编号与名称整体错位，且缺失 CH_PD/EN 使能上拉（不上拉模块无法启动）。ESP-01 为 8 脚 2×4 排针封装，以下按官方引脚定义重写。

| 引脚号 | 引脚名称 | 连接网络 / 功能说明 |
| ---: | --- | --- |
| 1 | GND | GND |
| 2 | GPIO2 | **LED_WIFI 输出**（驱动 LED6 蓝灯，active-low；模块内部已上拉，悬空即可，勿外接下拉） |
| 3 | GPIO0 | 经 10k (R3) 上拉至 +3V3（拉低进入下载模式；正常工作保持高） |
| 4 | RXD (GPIO3) | 接主控 TXD（引脚 16 / P3.1） |
| 5 | TXD (GPIO1) | 接主控 RXD（引脚 15 / P3.0） |
| 6 | CH_PD / EN | 经 10k (R5) 上拉至 +3V3（**必须上拉，否则模块不启动**） |
| 7 | RST (RESET) | 经 10k (R4) 上拉至 +3V3 |
| 8 | VCC | +3V3 |

| H1 | 3 | GND |

## 8. 蜂鸣器与指示灯模块

| 器件 | 引脚 | 连接关系 |
| --- | --- | --- |
| Q1 (S9012 PNP) | 基极 (B) | 经 R12 (1k) 接 BEEP（主控引脚 24） |
| Q1 | 发射极 (E) | GND |
| Q1 | 集电极 (C) | BUZZER1 负极 |
| BUZZER1 | 正极 | +5V |
| LED7 (红) | — | 阳极接 +3V3，阴极经 R13 (1k) 接 LED_T |
| LED6 (蓝, LED_WIFI) | — | 阳极接 +3V3，阴极经 R14 (1k) 接 **LED_WIFI**（由 ESP GPIO2 / 引脚2 驱动，属 ESP 侧，51 MCU 无对应引脚，故 51 侧不可测） |

> 蜂鸣器驱动 Q1 为 S9012 PNP，驱动为 active-low：`BEEP(P2.1)` 拉低 → Q1 导通 → 蜂鸣器响；拉高 → 截止静音。固件 `BEEP_ON()=P2&=~0x02`、`BEEP_OFF()=P2|=0x02`，启动务必先 `BEEP_OFF()`（STC15 端口上电锁存=1=高=停）。

## 9. 备注

> 本板无 J1–J4 连接器；P1/P2 外设引脚均已被 TM1639 显示驱动与传感器（R9 光敏电阻、RM1 热敏电阻）占用，无扩展接口。
