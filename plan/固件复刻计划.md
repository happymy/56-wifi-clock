# 51 单片机固件复刻计划（STC15W408AS）

> 复刻对象：原版 WiFi 时钟的 51 单片机固件。
> 参考文档：`plan/原理图.md`（引脚与器件连接）、`doc/原版时钟功能.md`（功能需求）。
> 范围：仅 51 侧固件（TM1639 显示、DS1302 时钟、按键、传感器、与 ESP8266 的 UART 通信协议）。ESP8266 自身固件（AT 或自定义）作为外设，不在本计划内，但需定义其串口接口。

## 0. 目标与验收基线
- 复刻后行为需逐项对照 `doc/原版时钟功能.md`：大屏三态（TIME `HH:MM` / DATE `MMDD` / TEMP `[符号][2位温度][C]`，**手动 UP 切换，无自动整屏轮显**）+ SMG2（秒/年份）+ SMG1（TIME 态按 `smg1_mode` 固定选显 温度°C/日期(日 DD)，温度时个位 dp 亮）、亮度（自动 LDR / 手动 1–8）、温度补偿（-8~+8°C）、三组独立闹钟（Web 设置）、时间设置（联网 NTP / 手动）、WiFi 配网（AP `56dz network clock` + 192.168.4.1）、时区、断电走时（CR1220）、状态指示灯。

## 1. 开发环境与工具链（建议）
- **编译器**：SDCC（开源，支持 STC 1T 8051）→ 备选 Keil C51。
- **烧录**：`stcgal`（开源命令行）/ 官方 STC-ISP；通过 USB-TTL（CH340）接 MCU 的 `P3.0(RXD)`/`P3.1(TXD)`，利用冷启动或 RST 引脚进入下载模式。
- **MCU 关键参数**（STC15W408AS）：1T 8051、内部 IRC 实测 11.051MHz（详见 doc/STC15W408AS-硬件选项.md；早期 35MHz 假设作废）、8KB Flash、512B RAM、~5KB 片内 EEPROM（存设置）、10-bit ADC（P1.0–P1.7）、3 个定时器、2 个外部中断（`P3.2/INT0=UP`、`P3.3/INT1=SET`）。

汇总为 `pins.h`：

| GM | P1.0 (ADC0) | 光敏电阻（自动亮度采样） |
| RM | P1.1 (ADC1) | 热敏电阻 NTC（温度采样） |
| LED_T | P1.2 | 红色指示灯控制 |
| CE | P1.3 | DS1302 片选 |
| DSDA | P1.4 | DS1302 数据 |
| DSCL | P1.5 | DS1302 时钟 |
| RXD | P3.0 | ← ESP8266 TXD |
| TXD | P3.1 | → ESP8266 RXD |
| UP | P3.2 (INT0) | 上调按键 |
| SET | P3.3 (INT1) | 功能按键 |
| BEEP | P2.1 | 蜂鸣器驱动（经 S9012 PNP Q1，active-low：拉低响） |
| STB | P2.3 | TM1639 片选 |
| SCL | P2.4 | TM1639 时钟 |
| SDA | P2.5 | TM1639 数据（DIO） |
| VCC / P5.5 / GND | 12 / 13 / 14 | 电源 |

> ⚠️ 第 1 节 SOP28 的 `VCC=12、P5.5=13、GND=14` 已依官方引脚表修正，复刻接线务必按此。

> ⛔ **安全约束（必须）**：`RXD(P3.0)`、`TXD(P3.1)` 接 ESP-01S（3.3V），51 为 5V，串口直连无电平转换。**P3.0/P3.1 必须保持准双向（复位默认，位=00），严禁设为强推挽（位=01）**——强推挽会以 5V 满电流驱动 ESP 的 RXD，超其耐压（绝对最大 3.6V）**直接烧毁 8266**。STC-ISP 硬件选项勿勾选任何把 P3.0/P3.1 设推挽的选项。详见 §14.2。

## 3. 显示驱动 TM1639（核心）
- **硬件**：3 线串口 `STB(P2.3)` 片选、`CLK(P2.4)` 时钟、`DIO(P2.5)` 数据（开漏，板上已接 R6/R7/R8 各 10K 上拉 + 滤波电容）。
- **命令集**（Titan Micro 官方 24 脚定义）：
  - 显示模式设置（8 段 × 8 位）；
  - 数据设置（地址自增 / 固定地址、写显示 / 读按键）；
  - 地址设置（00H–0FH，对应 GRID1–GRID8 × SEG1–8）；
  - 显示控制（显示开关 + 8 级占空比亮度）。
- **位映射（已确认）**：8 位数码管，GRID1–GRID8 满占 —— `LED2→GRID1`、`LED3→GRID2`、`LED4→GRID3`、`LED5→GRID4`（4× 单管 `FJ12101AH`，1.2"）；`SMG1`(0.56"双位 `5612B`)：`pin8→GRID6(左位)`、`pin7→GRID5(右位)`；`SMG2`(0.56"双位 `5612B`)：`pin8→GRID8(左位)`、`pin7→GRID7(右位)`。
- **物理排布（已确认）**：主行从左到右 `LED2→LED3→LED4→LED5`（GRID1–4，4×1.2" 大数码管）；其旁为上下两排 2 位数码管——**上排 SMG2**（GRID8 左位/pin8、GRID7 右位/pin7）、**下排 SMG1**（GRID6 左位/pin8、GRID5 右位/pin7）。各 GRID 显示内容（时分/秒/日期/温度）在固件中可配置。整体顺序见 §12。
- **字模**：0–9 及必要符号的**共阴**七段码表（`SEG1=a … SEG7=g`、`SEG8=dp`，字节序 `dp,g,f,e,d,c,b,a`）。料号核实：`FJ12101AH`=共阴（立创/LCSC 确认），`5612B`=共阴（与 TM1639 共阴恒流驱动拓扑一致）。
- **显示缓冲**：维护 `digit[0..N]` 与 `blink` 标志，定时刷新。

## 4. 实时时钟 DS1302
- 3 线（`CE=P1.3`、`I/O=P1.4`、`SCLK=P1.5`），单字节/突发读写，BCD ↔ 二进制编解码。
- 上电检测时钟是否有效（年/月/日/星期/时/分/秒合法），无效则写默认时间或从 ESP 同步。
- 备用电池 CR1220 维持走时；电池有字面为正极、正极朝上。
- 提供 `get_time()` / `set_time()`，供显示与闹钟使用。

## 5. 按键输入（SET / UP）
- `SET=P3.3(INT1)`、`UP=P3.2(INT0)`，软件消抖 + 状态机识别：
  - **单击 SET**：进入亮度调节（大屏闪显档位，UP 加减：0=自动光敏 / 1–8=手动），再次单击 SET 退出；
  - **双击 SET**：大屏显示 `P` + IP 末段并触发对时（Web 校时）；
  - **长按 SET**：进入时间设置（UP 增减当前编辑位、SET 切 时/分，再次长按退出）；
  - **UP**：设置态下增减当前编辑项；非设置态无作用（走时 SMG1 选显仅由 8266 `smg1_mode` 控制，无本地切模式键）。
- 实现：定时器 1ms 扫描 + 边沿中断，区分单击 / 双击（~300ms 窗）/ 长按（>1s，阈值可调）。
- ✅ **`demo/ds1302-clock` 已实现传统手动设置**（v0.5）：SET 单击进入并循环切换字段（时→分→秒→日→月→年→星期），UP 在当前字段加值（独立回绕、闰年感知），末字段 SET 保存+响蜂鸣。此为复刻阶段的手工设置方案，便于无配网时校对时间。
- ⬜ **产品语义（见 `doc/原版时钟功能.md`）仍待实现**：SET 单击/双击/长按分别进入显示/闹钟/时间设置，UP 增减；三组独立闹钟、EEPROM 持久化。当前 ds1302-clock 的按键逻辑为简化版，产品固件将在此基础上扩展。

## 6. 传感器采集
- **光敏 GM（P1.0, ADC0）**：10 位 ADC 采样。本板光敏电阻为**暗→阻值大→ADC 值高**（实测全黑 >1000，强光趋近 0），故映射 `lvl = 7 - (min(light,512)*7)/512`：暗(值≥512，含全黑)→档 0(最暗)、强光(值<~85)→档 7(最亮)，写 `TM1639 0x88|lvl`（占空比 1/16..14/16，显示保持点亮不熄灭）。`min(light,512)` 的 cap 使整个暗区(≥512)都落档 0(1/16)，再叠加软件 PWM 压到 ≈1/1024（见下条「已实现」）。TM1639 段为恒流驱动，档 0(1/16) 即芯片 8 级占空比下限（8 级为 1/16,2/16,4/16,10/16…14/16，非均匀）。要更暗需改板载限流电阻，或在固件做软件 PWM（间歇发 0x80/0x88 把有效占空比压到 1/16 之下）——原版时钟固件即用此法，须 ≥20-30fps 快速开关才不闪；当前慢主循环(≈240ms/轮)直接做会闪，须用定时器快切或仅极暗时启用。
- **极暗软件 PWM 已实现（`demo/clock-bringup`）**：定时器 T0(12T,0.0625ms 节拍) 中断 `__interrupt(1)` 间歇发 `0x80`(灭)/`0x88`(开,基档 1/16)，`PWM_STEPS=64`、`pwm_on_steps` 随暗度 64→1（光敏 512→1023 映射 100%→1.56%，有效 1/16→≈1/1024）；ISR 仅在相位边界写命令(周期 4ms 仅 2 次)，CPU 占用低。物理开关切换≈500Hz 无肉眼闪烁；亮区(≤512)走原 8 档硬件亮度并关 PWM。写显示/亮度命令时关 ET0 防插帧。调光比例 `on_steps/PWM_STEPS` 与节拍快慢无关，故 12T/1T 假设偏差只改闪烁频率不改亮度。
  - **热敏 RM（P1.1, ADC1）**：NTC 查表 / Steinhart-Hart 公式算温度 → 叠加温度补偿值（-8~+8°C，存 EEPROM）。*当前固件 `ntc_temp_x10` 用线性近似占位（B=4050、10K 上拉、零点 raw≈512），单点标定走 `temp_offset`；Steinhart-Hart 待精度升级，详见 `plan/原理图.md §9` NTC 注。*
- 采样由定时器触发，带去抖/平均。

## 7. ESP8266 WiFi 通信（UART 接口）
> ⚠️ 本节为早期草案；**权威串口协议以 `plan/串口通信协议.md` 为准**（伪待机、STA 按需连接、双击 SET 显示IP+对时、AP 配网一次性、54B 配置结构等）。
- 硬件 UART（`P3.0/P3.1`），波特率依模块固件（典型 9600 / 115200）。
- **协议状态机（规划）**：
  1. 未配网：ESP 进入 AP 模式热点 `56dz network clock`（密码 `56dz.com`），网页配置由 ESP 内部 HTTP Server（192.168.4.1）实现；51 仅通过串口读取“配网完成/失败”事件。
  2. 联网后：51 发 AT / 自定义指令让 ESP 获取 NTP 时间（带时区，如 UTC+8），返回时间串/帧；51 解析后写入 DS1302。
  3. 自动重连、热点自动开关由 ESP 固件处理；51 通过状态引脚或串口事件感知 WiFi / 同步状态，驱动指示灯。
- 限制：仅 2.4GHz；状态灯（闪烁=连接中，常亮=成功，灭=超时；同步灯亮=已同步）由 51 控制。
- **配网触发（已确认设计）**：上电若 EEPROM 无有效 WiFi 凭据 → 进 AP 配网；另支持 **UP(P3.2) 与 SET(P3.3) 同时按住 ≥5s** → 清除凭据并软复位进入 AP 模式重新配网（后期可由“上电配网”改为仅按键触发，接口预留）。

## 8. 设置持久化（EEPROM）
  - **容量（已确认）**：STC15W408AS 片内 EEPROM = **5K 字节**，按 **512 字节/扇区**（共 10 扇区），**起始地址 0x0000**（地址空间 0x0000–0x13FF；不同型号地址不同，408AS 固定 0x0000）。
  - **CODE（固件区）容量（已确认）**：STC15W408AS 片内 Flash = **8192 字节（8KB）**，为代码取指执行区，SDCC `--code-size 8192` 即其上限；当前固件占用 **8182B（0x1FF6，余 10B，实测 `firmware/STC/out/firmware.ihx`）**。EEPROM 为独立数据空间，不可执行、不计入 CODE。容量取舍详见 `plan/新版时钟功能.md` §十八。
- 片内 EEPROM 保存：显示模式、亮度档、温度补偿值、3 组闹钟（时/分/开关）、时区、是否已配网标志（同一次修改的数据放同一扇区）。
- **IAP 访问**：`IAP_CONTR(0xC7)` 使能 + 等待时间(按 11.051MHz 实测 IRC 配 WT 位)、`IAP_CMD(0xC5)` 命令（`0x01`读/`0x02`写/`0x03`扇区擦除）、`IAP_ADDRH(0xC3)/IAP_ADDRL(0xC4)`、`IAP_DATA(0xC2)`，触发序列 `0x5A→0xA5`；写前须整扇区擦除（512B），操作期间关中断。提供 `eeprom_read()/eeprom_write()/eeprom_erase_sector()` 封装。

## 9. 主循环与定时
- `T0`：极暗软件 PWM 快切（0.0625ms 节拍，§6 已占用）；由其 ISR 相位计数器派生 1s 基准 tick 与扫描/按键/ADC 节拍（芯片无 Timer1，T2 已作 UART1 波特源，故不另分配定时器）。
- `T2`：UART1 波特源（9600 8N1，`demo/uart-test` 已验证）。
- 主循环：tick → 更新时间/温度 → 按当前模式合成显示 → 写 TM1639；处理按键 → 进入对应设置态；处理 ESP 事件 → 同步时间/更新状态灯；到点检查闹钟 → 蜂鸣器响。

## 10. 蜂鸣器与指示灯
- `BEEP=P2.1`：经 **S9012 PNP Q1** 驱动（active-low：拉低响、拉高停）。⚠️ 原理图误标 NPN，实物为 PNP。
  - 报警音用**稳态低电平脉冲**（响 250ms / 停 250ms × 4 ≈ 2s），**不用 PWM**：板载为有源蜂鸣器，PWM 斩波会令音调发劈、音量不稳。
  - 上电显示先出、延时 300ms 后再响 2 秒（经典 BB）。
  - 两键同按期间蜂鸣器持续响，松开即停。
- 指示灯：`LED_T(P1.2 红)`、`LED_WIFI(蓝，原图标 LED6，由 ESP GPIO2/引脚2 驱动，属 ESP 侧，MCU 无对应引脚，故不可测)`；WiFi / 同步状态灯按第 7 节逻辑驱动（物理位置需依板确认）。

## 12. 风险与待确认项（更新）
### 已确认（料号查证 / 芯片手册）
- 数码管位数与 GRID 映射：8 位（LED2-5→GRID1-4，SMG1→GRID5/6，SMG2→GRID7/8），见 §3。
- 极性：共阴（FJ12101AH 立创/LCSC 确认；5612B 共阴，与 TM1639 共阴恒流驱动一致），见 §3。
- EEPROM：5K 字节 / 512 字节扇区 / 起始 0x0000（地址空间 0x0000–0x13FF），见 §8。
- ESP8266 通信协议：自定（51 侧接口由本计划设计，不阻塞）。

### 设计决定（已确认 / 授权固件自定义）
- **指示灯拓扑**：51 侧 LED 仅 `LED_T`(红, P1.2/pin5)。WiFi 状态灯即 `LED_WIFI` = 外接 LED6(蓝)，由 ESP GPIO2(引脚2) 驱动，属 ESP 侧，51 无对应引脚（故 51 固件不可测，也无“51 引脚待补”之说）；ESP-01S 板载 LED 同样接 GPIO2，与此外接 LED6 同信号，勿混淆。本阶段(点亮数码管)暂不涉及。
- **数码管显示布局（固件自定义）**：大屏 4 大数码管(LED2-5 = GRID1–4) **整屏三态（手动 UP 切换，无自动轮显）**〔注：产品固件已实现 `display_mode=1` 自动轮显，与 v2 规格 §十三 一致；本句「无自动轮显」为早期复刻计划描述，以 v2 规格为准〕——TIME `HH:MM`（冒号=GRID2/GRID3 小数点，GRID3 倒装、个位小数点作下点）、DATE `MMDD`（月左/日右镜像）、TEMP `[符号][2位温度][C/F]`（NTC 无效兜底 25°C；°F 由 `cfg.temp_unit` 切换，SMG1 温度恒°C）；上排 SMG2(GRID7/8)：TIME 显秒 `SS`、DATE 显年份 `YY`、TEMP 灭；下排 SMG1(GRID5/6)：**仅 TIME 态**按 `smg1_mode` 固定选显 **温度 °C / 日期(日 DD)**（0=温度、1=日期，不轮换；DATE 态显星期 1–7、TEMP 态灭；**SMG1 凡显温度个位(GRID5)小数点恒亮**）。手动设日期按真实月末封顶（大小月正确；Feb 闰年 2/29，本地按 (年%4) 判定，2026–2099 正确，2100 边界忽略）。冒号/小数点依料号段位而定。
- **UP 键(P3.2) 非设置态**：单击循环整屏模式 TIME→DATE→TEMP→TIME；双击恢复走时(TIME)；**长按 UP** 进入/退出计时器（51 原生，V1 已实装，首秒不漏不快，见 `新版时钟功能.md` §四）。倒计时由 8266 负责，显示期间 单击/长按 SET 经 `CD_CTRL(0x05)` 接管（暂停/恢复、取消）。
- **端口复核提示**：引脚以 `plan/原理图.md` 为准；实测 LED/DS1302 不响应时优先复核 SOP28 pin5/pin6 端口标注。

## 13. 显示点亮里程碑实测坑点（已完成）

> 阶段目标：让 8 位数码管正常显示，并核对 GRID 顺序。已用 SDCC 编译 + STC-ISP 烧录验证通过。

### 13.1 必须注意的 4 个坑（固件层）
1. **上电延时**：`main()` 一开始必须 `delay_ms(200)` 再向 TM1639 发首条命令。实测不发延时 → TM1639 上电未稳、吞掉唯一一次初始化 → 8 管全灭（原诊断固件只发一次，中招）。持续刷屏可补救，但上电延时更稳。
2. **段字节拆分（关键）**：24 脚封装 SEG5–SEG8 未引出，E/F/G/DP 实际在 SEG9–SEG12（**高字节**）。每 GRID 必须发 2 字节：`[data & 0x0F, (data >> 4) & 0x0F]` —— 低字节=SEG1–4(a–d)，高字节=SEG9–12(e–g,dp)。若按 8 段一次性发 `[data, 0x00]`，e/f/g/dp 落在低字节 bit4–7（不连到这些段）→ 数字残缺。
3. **倒装管**：第 3 位大数码管 `LED4`（GRID3）物理倒装 180°，段码需 `seg_rotate180()` 补偿（a↔d, b↔e, c↔f, g↔g, dp↔dp），否则正常字形显成镜像（如 `3`→`E`）。
4. **stcgal 握手失败**：本板用官方 **STC-ISP** 烧录（`stcgal -P stc15` 握手不进下载模式）。USB 供电线与 COM 串口线是两路，须冷启动/RST 触发。
5. **按键轮询空隙漏单击**：主循环每 250ms 只读一次按键，单击若 <250ms 落在轮询空隙即被漏掉（需按两次）。修复：把按键扫描拆成 250ms 内的快扫（12×20ms≈240ms），边沿检测每 20ms 一次，单击不再漏。

### 13.2 已核对一致的假设（实测印证，无需改）
- DS1302 引脚 `CE=P1.3 / DSDA(IO)=P1.4 / DSCL(SCLK)=P1.5`（§2/§4 正确）。
- 段序 `SEG1=a…SEG7=g, SEG8=dp`，共阴字模（§3 正确）。
- GRID 映射：`LED2-5→GRID1-4`、`SMG1: GRID6=左/GRID5=右`、`SMG2: GRID8=左/GRID7=右`（§3 正确）。整板从左到右读数 `12345678`（大屏 1234 + SMG1 56 + SMG2 78）验证通过。
- 红灯 `LED_T` = `P1.2`（pin5），心跳/运行指示可用（§10 正确）。

## 14. 调试方法与 IO 安全约束

### 14.1 调试通道
- **上电自动检测 8266（主调试路径）**：51 上电监听 ~5s 等 ESP 启动帧 `BOOT(0x8F)`（或任意合法帧）。**未检测到 → 蜂鸣器响 3 声，进入调试模式**：UART1 转作**极详细日志（very verbose）**——启动状态、EEPROM 配置全 dump（54B hex）、DS1302 时间、ADC 光/温原始值、按键事件、状态机迁移；UART 收发的**每字节 hex dump** + 解析后的帧（CMD/LEN/PAYLOAD/CHK）。同时把串口收到的字节按 8266 协议帧解析，**人工用 PC 串口终端发数据即可模拟 8266**（如手动发 `SET_TIME`/`SET_CFG`/`NET_STATUS`/`STA_IP` 驱动 51 逻辑）。此模式不连真实 8266，可安全全量打印；烧入真实 8266 固件后上电检测到 → 自动正常模式、日志关闭。详见 `串口通信协议.md` §9。
- **数码管显示调试码**：用 TM1639 在管上滚显状态/错误码（`dbg`+2 位），零额外硬件，正常/调试模式均可。
- **EEPROM 环形日志**：预留末扇区 `0x1000–0x13FF`（512B，与配置区隔离）作 trace ring buffer；关键路径 `log_event(code,val)` 写入，事后 STC-ISP 读出或长按 UP 导出。
- ESP 侧调试走其自身 WiFi console，不占 51 串口。

### 14.2 ⛔ 硬性安全约束：P3.0/P3.1 严禁强推挽（会烧毁 8266）
- 51 为 +5V、ESP 为 +3.3V，串口直连无电平转换；ESP8266 IO 非 5V 耐受（绝对最大 3.6V）。
- STC15 IO 模式由 `P3M1/P3M0` 配置。**P3.0(RXD)、P3.1(TXD) 必须保持准双向（位=00，复位默认）**。
- ⛔ **绝不可设为强推挽（位=01）**：强推挽以 5V 满电流驱动 ESP 的 RXD，超出耐压 → **烧毁 8266**。即使其它 P3 脚需推挽，也必须单独保住 P3.0/P3.1 为准双向。
- 烧录工具 STC-ISP 硬件选项**勿**勾选任何把 P3.0/P3.1 设推挽/输出增强的项（默认即准双向，勿改）。
- 任何新增调试/功能 IO 也用准双向，避免误连 ESP 线导致过压。
