# 51 单片机固件复刻计划（STC15W408AS）

> 复刻对象：原版 WiFi 时钟的 51 单片机固件。
> 参考文档：`plan/原理图.md`（引脚与器件连接）、`doc/原版时钟功能.md`（功能需求）。
> 范围：仅 51 侧固件（TM1639 显示、DS1302 时钟、按键、传感器、与 ESP8266 的 UART 通信协议）。ESP8266 自身固件（AT 或自定义）作为外设，不在本计划内，但需定义其串口接口。

## 0. 目标与验收基线
- 复刻后行为需逐项对照 `doc/原版时钟功能.md`：时间/日期/温度显示、显示模式（固定/自动切换）、亮度（自动 LDR / 手动 1–8）、温度补偿（-8~+8°C）、三组独立闹钟、时间设置（联网 NTP / 手动）、WiFi 配网（AP `56dz network clock` + 192.168.4.1）、时区、断电走时（CR1220）、状态指示灯。

## 1. 开发环境与工具链（建议）
- **编译器**：SDCC（开源，支持 STC 1T 8051）→ 备选 Keil C51。
- **烧录**：`stcgal`（开源命令行）/ 官方 STC-ISP；通过 USB-TTL（CH340）接 MCU 的 `P3.0(RXD)`/`P3.1(TXD)`，利用冷启动或 RST 引脚进入下载模式。
- **MCU 关键参数**（STC15W408AS）：1T 8051、内部 IRC 35MHz、8KB Flash、512B RAM、~5KB 片内 EEPROM（存设置）、10-bit ADC（P1.0–P1.7）、3 个定时器、2 个外部中断（`P3.2/INT0=UP`、`P3.3/INT1=SET`）。

## 2. 引脚映射（来自 `plan/原理图.md`，已按官方表修正 VCC=12 / P5.5=13）
汇总为 `pins.h`：

| 信号 | 引脚 | 功能 |

| GM | P1.0 (ADC0) | 光敏电阻（自动亮度采样） |
| RM | P1.1 (ADC1) | 热敏电阻 NTC（温度采样） |
| LED_T | P1.2 | 红色指示灯控制 |
| CE | P1.3 | DS1302 片选 |
| DSDA | P1.4 | DS1302 数据 |
| DSCL | P1.5 | DS1302 时钟 |
| RXD | P3.0 | ← ESP8266 TXD |
| TXD | P3.1 | → ESP8266 RXD |
| UP | P3.2 (INT0) | 上调按键 |
| SET | P3.3 (INT1) | 功能按键 |
| BEEP | P2.1 | 蜂鸣器驱动（经 NPN Q1） |
| STB | P2.3 | TM1639 片选 |
| SCL | P2.4 | TM1639 时钟 |
| SDA | P2.5 | TM1639 数据（DIO） |

> ⚠️ 第 1 节 SOP28 的 `VCC=12、P5.5=13、GND=14` 已依官方引脚表修正，复刻接线务必按此。

## 3. 显示驱动 TM1639（核心）
- **硬件**：3 线串口 `STB(P2.3)` 片选、`CLK(P2.4)` 时钟、`DIO(P2.5)` 数据（开漏，板上已接 R6/R7/R8 各 10K 上拉 + 滤波电容）。
- **命令集**（Titan Micro 官方 24 脚定义）：
  - 显示模式设置（8 段 × 8 位）；
  - 数据设置（地址自增 / 固定地址、写显示 / 读按键）；
  - 地址设置（00H–0FH，对应 GRID1–GRID8 × SEG1–8）；
  - 显示控制（显示开关 + 8 级占空比亮度）。
- **段/位映射**：逻辑 `SEG1–SEG8` = 物理 `SEG1–4(KS1–4)` + `SEG9–12`；`GRID1–GRID8` 为位选。按原理图标定：`GRID1→LED2`（单数码管）、`GRID5→SMG1 右位`、`GRID6→SMG1 左位`。
- **字模**：0–9 及必要符号的七段码表（含 DP），共阴/共阳需与实际数码管一致（见风险项）。
- **显示缓冲**：维护 `digit[0..N]` 与 `blink` 标志，定时刷新。

## 4. 实时时钟 DS1302
- 3 线（`CE=P1.3`、`I/O=P1.4`、`SCLK=P1.5`），单字节/突发读写，BCD ↔ 二进制编解码。
- 上电检测时钟是否有效（年/月/日/星期/时/分/秒合法），无效则写默认时间或从 ESP 同步。
- 备用电池 CR1220 维持走时；电池有字面为正极、正极朝上。
- 提供 `get_time()` / `set_time()`，供显示与闹钟使用。

## 5. 按键输入（SET / UP）
- `SET=P3.3(INT1)`、`UP=P3.2(INT0)`，软件消抖 + 状态机识别：
  - **单击 SET**：进入显示设置（显示模式 / 亮度 / 温度补偿循环）；
  - **双击 SET**：进入闹钟设置（3 组独立闹钟）；
  - **长按 SET**：进入时间设置；
  - **UP**：设置态下增减当前编辑项。
- 实现：定时器 1ms 扫描 + 边沿中断，区分单击 / 双击（~300ms 窗）/ 长按（>1s，阈值可调）。

## 6. 传感器采集
- **光敏 GM（P1.0, ADC0）**：多次采样平均 → 映射为亮度等级（0 = 自动，由 TM1639 占空比体现）。
- **热敏 RM（P1.1, ADC1）**：NTC 查表 / Steinhart-Hart 公式算温度 → 叠加温度补偿值（-8~+8°C，存 EEPROM）。
- 采样由定时器触发，带去抖/平均。

## 7. ESP8266 WiFi 通信（UART 接口）
- 硬件 UART（`P3.0/P3.1`），波特率依模块固件（典型 9600 / 115200）。
- **协议状态机（规划）**：
  1. 未配网：ESP 进入 AP 模式热点 `56dz network clock`（密码 `56dz.com`），网页配置由 ESP 内部 HTTP Server（192.168.4.1）实现；51 仅通过串口读取“配网完成/失败”事件。
  2. 联网后：51 发 AT / 自定义指令让 ESP 获取 NTP 时间（带时区，如 UTC+8），返回时间串/帧；51 解析后写入 DS1302。
  3. 自动重连、热点自动开关由 ESP 固件处理；51 通过状态引脚或串口事件感知 WiFi / 同步状态，驱动指示灯。
- 限制：仅 2.4GHz；状态灯（闪烁=连接中，常亮=成功，灭=超时；同步灯亮=已同步）由 51 控制。

## 8. 设置持久化（EEPROM）
- 片内 EEPROM 保存：显示模式、亮度档、温度补偿值、3 组闹钟（时/分/开关）、时区、是否已配网标志。
- 提供 `eeprom_read()` / `eeprom_write()` 封装，掉电不丢。

## 9. 主循环与定时
- `T0`：1s 基准 tick（DS1302 走时、显示刷新节拍）。
- `T1`：显示扫描 / 按键扫描 / ADC 采样节拍（如 1–10ms）。
- 主循环：tick → 更新时间/温度 → 按当前模式合成显示 → 写 TM1639；处理按键 → 进入对应设置态；处理 ESP 事件 → 同步时间/更新状态灯；到点检查闹钟 → 蜂鸣器响。

## 10. 蜂鸣器与指示灯
- `BEEP=P2.1`：闹钟/提示音（翻转 IO 产生方波或 PWM，持续若干秒）。
- 指示灯：`LED_T(P1.2 红)`、`LED_W(绿，原图标为 LED6，原理图标明“主控修正版无对应引脚、疑似悬空或与 LED_T 共线”→ 需确认)`；WiFi / 同步状态灯按第 7 节逻辑驱动（物理位置需依板确认）。

## 11. 构建 / 烧录 / 验证
- SDCC 编译 → `stcgal` 烧录 → 上电验证：
  - 时间/日期/温度显示正常；自动/手动亮度；温度补偿生效；
  - 三组闹钟触发蜂鸣；SET 单击/双击/长按分别进入对应设置；UP 调整；
  - 断主电后 DS1302 由电池维持走时，重新上电时间连续；
  - WiFi 配网（AP `56dz network clock` / 192.168.4.1）、时区、自动重连、状态灯符合 `doc/原版时钟功能.md`。
- 逐项对照 `doc/原版时钟功能.md` 验收。

## 12. 风险与待确认项
- **数码管总数与 GRID 映射**：原理图仅详 `LED2`（1 位）+ `SMG1`（2 位），但规格称“4 位 1.2 寸 + 2 位 0.56 寸”，需上板确认实际位数与每个位对应的 GRID 编号。
- **共阴/共阳极性**：影响七段码表，需实测或查数码管料号。
- **LED_W / WiFi / 同步状态灯**：原理图标注不一致（LED6 疑似悬空），需确认物理位置与驱动方式。
- **ESP8266 侧固件与串口协议**：需逆推或参考原模块（AT 指令集 / 自定义帧格式），本计划仅定义 51 侧接口。
- **按键时间窗阈值**：300ms / 1s 为初值，依手感调参。
