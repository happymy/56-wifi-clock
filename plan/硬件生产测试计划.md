# 硬件生产测试计划（HWTEST）

> 目的：在产线/维修环节用一片固件对整板做一次全功能自检，快速暴露虚焊、漏焊、错件、断线。
> 配套固件：`demo/hw-test/`（SDCC 编译，`build.bat` 产出 `out/firmware.hex`）。
> ESP-01S 为成品模块，本测试不覆盖；其占用的 UART1 改用 **P3.0↔P3.1 直连回环** 自测。

## 1. 测试前准备

| 项 | 要求 |
|---|---|
| 编程器 | STC-ISP（USB 转串口 + 冷启动上电），芯片选 STC15W408AS |
| IRC | 内部 IRC 11.051MHz（STC-ISP 硬件选项读出值；固件按此标定，误差 <0.2% 在 UART 容限内） |
| 短接 | 用杜邦线把 **P3.0(RXD) 与 P3.1(TXD)** 短接（UART 回环必需） |
| 上电 | 给板子供 5V/3.3V，确认 DS1302 备份电池在位 |
| 观察 | 串口终端 9600 8N1（日志为 ASCII 英文）；肉眼看数码管 8 管 + 上排步骤号 + 红色状态灯；耳朵听蜂鸣器 |
| 按键 | 空板按键上拉为内部弱上拉，未按读高、按下读低（GND） |

## 2. 测试项与信号映射

| # | 测试项 | 信号/引脚 | 方法 | 自动判定 | 失败含义 |
|---|---|---|---|---|---|
| T1 | 显示自检 | TM1639 STB/SCL/SDA = P2.3/2.4/2.5 | 8 管全段(0xFF)点亮，肉眼查每管每段（步骤号 SMG2=01 闪烁提示确认） | 否（肉眼） | 段缺/错位 = 数码管/驱动虚焊或断线、倒装管装反 |
| T2 | 实时时钟 | DS1302 CE/IO/SCLK = P1.3/1.4/1.5 | 主屏显 `HH:MM`、SMG1 显 `SS` 走时 5s；停振则写时间后复读；判秒前进 | 是（走时） | XTAL/DS1302 未起振或虚焊。**仅证上电在走时，不验证断电保持** |
| T3 | 串口回环 | UART1 P3.0/3.1 | 左发右显：发 `00`..`FF` 共 256 字节并回收比对（沿用 uart-test 回环布局），末显 `HP` 保持 5s（SMG2=03） | 是 | P3.0/3.1 未短接或 UART 引脚虚焊 |
| T4 | 按键 | UP=P3.2, SET=P3.3 | 主屏显 `0000`；SET 加高位+1、UP 加低位+1（左右对应加1），5s 内两键都按过即 PASS（SMG2=04） | 是 | 按键/上拉/走线断 |
| T5 | 蜂鸣器 | BEEP=P2.1 | 蜂鸣器重复响 3 次（SMG2=05） | 否（人耳） | 蜂鸣器/驱动虚焊 |
| T6 | 状态灯 | LED_T=P1.2 | 红 LED 闪烁 5s（SMG2=06） | 否（肉眼） | LED 或限流电阻虚焊 |
| T7 | 光敏 | GM=P1.0 (ADC ch0) | 主屏显示 10 位 ADC 原值 5s（SMG2=07） | 是 | 读到 0 或 1023 = 开路/短接 |
| T8 | 热敏 | RM=P1.1 (ADC ch1) | 主屏显示 10 位 ADC 原值 5s（SMG2=08） | 是 | 读到 0 或 1023 = 开路/短接 |
| T9 | 片内 EEPROM | IAP 总线（ADDR 0xC3/0xC4、DATA 0xC2、CMD 0xC5、TRIG 0xC6、CONTR 0xC7） | 擦末扇区 0x1200(512B)→回读全 0xFF；再写 0x5A/0xA5/0x3C 读回比对；通过主屏显 `01`、错误显 `EE`，结果保持 5s（SMG2=09）；`IAP_CONTR=0x84`（IAPEN + WT=100，适配 11.051MHz） | 是 | IAP 总线/EEPROM 虚焊或地址错（触发失败 CMD_FAIL） |
| T10 | 断电保持（最后一项，人工复核） | DS1302 VCC1 = CR1220 | SMG2=10，主屏显 `boot_action` 结果 5s（0=PASS/1,2=需切电复核） | 否（人工） | 切主电≥3s 再上电仍 `1/2` 或时间归零 = CR1220 没电、反装或虚焊 |

> 自动判定项：T2/T3/T4/T7/T8/T9 失败置位 `g_fail`；T1/T5/T6 肉眼/人耳确认；T10 人工项不进 `g_fail`。串口日志为 ASCII 英文，避免终端编码乱码。

## 3. 显示与声音提示

- **步骤号常驻（上排 SMG2，GRID7/8）**：全程显示 `01`~`10`，不看串口也知道测到哪一项。**确认步骤（T1/T5/T6）步骤号闪烁**提示“需人工”，其余自动步常亮。
- **主屏（GRID1-4）+ SMG1（GRID5/6）逐项内容**：
  - T1 全段点亮；T2 主屏 `HH:MM`、SMG1 `SS`；T3 左发 `TX`、右收 `RX`（末显 `HP`）；T4 `0000` 计数器（SET 加高位、UP 加低位）；T5 `bEEP`；T6 `LED`；T7/T8 显 ADC 原值；T9 通过 `01` / 错误 `EE`；T10 显 `boot_action`。
  - 自动步结束主屏闪现 **`0`（0x3F=过）/ `E`（0x79=败）**，SMG2 仍保留步骤号，哪步失败一眼可辨。
- **测试结束**：
  - **全过**：8 管显示 `0`，蜂鸣器发**双短音**；串口打印 `ALL PASS`。
  - **有失败**：8 管显示 `E`，蜂鸣器发**长音(600ms)**；串口打印 `FAIL mask=<hex>`，定位失败项（bit0=T1…bit8=T9(EEPROM)；bit9 不使用，T10 为人工项）。
- 保持结果画面；**两键(UP+SET)同按**可重跑整套测试。

## 4. 执行步骤

1. 烧录 `out/firmware.hex`，冷启动上电。
2. 短接 P3.0↔P3.1（建议焊点旁飞线或测试夹，量产可做成测试治具短接点）。
 3. 开串口终端 9600 8N1，应见 `HWTEST boot` → `==== HW TEST ====` 及逐项 `T1..T10` 日志。
 4. 按日志与提示依次确认：
     - T1 看 8 管全段亮（步骤号闪烁时按 SET 或等 ~4s 继续）。
     - T2 主屏走时 `HH:MM`、SMG1 `SS`，5s 后自动进 T3。
     - T3 左发右显 `00`→`FF`，末显 `HP` 保持 5s 进 T4（需 P3.0-P3.1 短接）。
     - T4 主屏 `0000`；按 SET 高位+1、按 UP 低位+1，5s 内两键都按过即过。
     - T5 听蜂鸣 3 次；T6 看红灯闪 5s；T7/T8 看主屏 ADC 原值 5s。
     - T9 通过显 `01`、错误显 `EE`，保持 5s；T10 显 `boot_action` 5s（人工切电复核见 §5）。
 5. 末项 T10 为断电保持人工复核（见 §5）；其 `boot_action` 打印后，末行 `ALL PASS`/`FAIL mask=..` + 屏显 `0`/`E` 为最终判定。
6. 不合格板记录 mask 位 → 对应信号返修；返修后两键重测。

## 5. 断电保持测试（T10，人工步骤，置最后）

> DS1302 断电走时靠 CR1220 维持，固件无法自行切断主电源，故为人工操作，且排在全套测试最后。判定信号复用 `ds1302.c` 的 `g_ds_init_action`（与 `ds1302-clock` 已验证的断电走时逻辑一致）：上电首读 CH 位，0=保住走时 / 1=掉电停振 / 2=BCD非法。

1. 看 T10 打印的 `boot_action`：为 `0` 即电池保住走时，直接 PASS；为 `1`/`2` 则进入切电复核。
2. 切断整板主电源（拔 USB / 断 VCC），保持 **≥3 秒**。
 3. 重新上电，冷启动进入 HWTEST，T10 再次打印 `boot_action`。
4. 判定：切电后 `boot_action=0` 且时间连续 → 断电保持合格；仍为 `1`/`2` 或时间归零 → CR1220 没电/反装（有字面应朝上）/虚焊 → 不合格。

> 风险说明：若不加人工核对，仅靠自动 T2，死电池会在上电后被 `ds1302_init()` 改写默认时间而**误判 PASS**；故 T10 必须人工确认时间未被重置。

## 6. 已知未覆盖项（产线/设计说明）

- **MCU 片内 EEPROM**：已通过 T9 自测（擦/写读回末扇区 0x1200，地址空间 0x0000–0x13FF、5K、扇区 512B；`IAP_CONTR=0x84` 按 11.051MHz 配 WT=100）。仅验证连通性/虚焊，不测擦写寿命与长期保持。
- **AMS1117-3.3 稳压**：MCU 由 +5V 直供（U3 pin12），故 1117 虚焊**不会**导致 MCU 停摆。但红灯 LED_T（LED7）阳极接 +3V3（§8），T6 要点亮须 +3V3 在场 → **1117 故障会表现为 T6 失败，被间接覆盖**。仅 ESP 侧（3.3V→ESP）仍超出 51 侧范围（ESP 按要求排除），靠成品模块/万用表确认。
- **蓝灯 LED6（LED_W）**：由 ESP-01S（ESP8266）驱动（LED_W 网络在 MCU 修正版无对应引脚，§8），未连 MCU，**不可测**。
- **Micro USB 供电（+5V）**：板子能冷启动跑完 T1–T8 即隐含 5V 正常；由操作员确认上电。

## 7. 通过准则

- `FAIL mask=00` 且屏显 `0` 且双短音 → **合格**。
- 任一自动项失败（mask 非 0）→ **不合格**，按位返修。
- T1/T5/T6 若产线员肉眼/人耳确认异常，即便 mask=0 也应判定不合格（属人工复核项）。

- UART 配置（Timer2 作波特源、9600、P3.1 推挽）沿用 `demo/uart-test` 已验证实现。
- 按键/蜂鸣/ADC 读法沿用 `demo/clock-bringup` 模式。
- 硬件引脚定义见 `plan/原理图.md` 与 `plan/固件复刻计划.md` §2。
