# 硬件生产测试计划（HWTEST）

> 目的：在产线/维修环节用一片固件对整板做一次全功能自检，快速暴露虚焊、漏焊、错件、断线。
> 配套固件：`demo/hw-test/`（SDCC 编译，`build.bat` 产出 `out/firmware.hex`）。
> ESP-01S 为成品模块，本测试不覆盖；其占用的 UART1 改用 **P3.0↔P3.1 直连回环** 自测。

## 1. 测试前准备

| 项 | 要求 |
|---|---|
| 编程器 | STC-ISP（USB 转串口 + 冷启动上电），芯片选 STC15W408AS |
| IRC | 内部 IRC 11.051MHz（STC-ISP 硬件选项读出值；固件按 11.063MHz 标定，误差 <0.2% 在 UART 容限内） |
| 短接 | 用杜邦线把 **P3.0(RXD) 与 P3.1(TXD)** 短接（UART 回环必需） |
| 上电 | 给板子供 5V/3.3V，确认 DS1302 备份电池在位 |
| 观察 | 串口终端 9600 8N1；肉眼看数码管 8 管 + 红色状态灯；耳朵听蜂鸣器 |
| 按键 | 空板按键上拉为内部弱上拉，未按读高、按下读低（GND） |

## 2. 测试项与信号映射

| # | 测试项 | 信号/引脚 | 方法 | 自动判定 | 失败含义 |
|---|---|---|---|---|---|
| T1 | 显示自检 | TM1639 STB/SCL/SDA = P2.3/2.4/2.5 | ①8 管全段(0xFF)点亮，肉眼查每管每段；②显示 `12345678` 查 GRID 顺序与倒装管方向 | 否（肉眼） | 段缺/错位 = 数码管/驱动虚焊或断线、倒装管装反 |
| T2 | 实时时钟 | DS1302 CE/IO/SCLK = P1.3/1.4/1.5 | 读时→轮询到秒变化→复读，秒前进 ≈1s；停振则写时间后复读；打印 CH 位与当前时间 | 是（走时） | XTAL/DS1302 未起振或虚焊。**注意：仅证上电在走时，不验证断电保持** |
| T3 | 串口回环 | UART1 P3.0/3.1 | 发 6 字节模式(55/AA/00/FF/12/34)并回收比对 | 是 | P3.0/3.1 未短接或 UART 引脚虚焊 |
| T4 | 按键 | UP=P3.2, SET=P3.3 | 提示后各等待按下最多 5s | 是 | 按键/上拉/走线断 |
| T5 | 蜂鸣器 | BEEP=P2.1 | 鸣 300ms | 否（人耳） | 蜂鸣器/驱动虚焊（无法自动听声） |
| T6 | 状态灯 | LED_T=P1.2 | 红 LED 闪烁 4 次 | 否（肉眼） | LED 或限流电阻虚焊 |
| T7 | 光敏 | GM=P1.0 (ADC ch0) | 读 10 位 ADC 原值 | 是 | 读到 0 或 1023 = 开路/短接 |
| T8 | 热敏 | RM=P1.1 (ADC ch1) | 读 10 位 ADC 原值 | 是 | 读到 0 或 1023 = 开路/短接 |
| T9 | 片内 EEPROM | IAP 总线（ADDR 0xC3/0xC4、DATA 0xC2、CMD 0xC5、TRIG 0xC6、CONTR 0xC7） | 擦末扇区 0x1200(512B)→回读全 0xFF；再在 0x1200/0x1201/0x12FF 写 0x5A/0xA5/0x3C 并读回比对；`IAP_CONTR=0x84`(IAPEN + WT=100，适配 11.051MHz) | 是 | IAP 总线/EEPROM 虚焊或地址错（触发失败 CMD_FAIL） |
| T10 | 断电保持（最后一项，人工复核） | DS1302 VCC1 = CR1220 | 上电首读 `boot_action`：0=电池保住走时(PASS)；1/2=上电停振(新板或电池失效)，已启动时钟；见 §5 切电复核 | 否（人工） | 切主电≥3s 再上电仍 `boot_action=1/2` 或时间归零 = CR1220 没电、反装或虚焊 |

> 自动判定项：T2/T3/T4/T7/T8/T9 失败会置位 `g_fail` 对应位；T1/T5/T6 由产线员肉眼/人耳确认（固件打印 `operator confirm`）；T10 为人工项，不进 `g_fail`。

## 3. 显示与声音提示

- 测试进行中：大屏(GRID1-4)显示当前测试号 `01`~`10`（GRID2 用 `seg_rotate180` 镜像，与时钟显示方向一致）；小屏不显示。
- 测试结束：
  - **全过**：8 管显示 `0`（0x3F），蜂鸣器发**双短音**；串口打印 `ALL PASS`。
  - **有失败**：8 管显示 `E`（0x79），蜂鸣器发**长音(600ms)**；串口打印 `FAIL mask=<hex>`，定位失败项（bit0=T1…bit8=T9(EEPROM)；bit9 不使用，T10 为人工项）。
- 保持结果画面；**两键(UP+SET)同按**可重跑整套测试。

## 4. 执行步骤

1. 烧录 `out/firmware.hex`，冷启动上电。
2. 短接 P3.0↔P3.1（建议焊点旁飞线或测试夹，量产可做成测试治具短接点）。
 3. 开串口终端 9600 8N1，应见 `HWTEST boot` → `==== HW TEST ====` 及逐项 `T1..T10` 日志。
 4. 按日志与提示依次确认：
    - T1 看 8 管全段亮；按 SET 或等 3s 继续。
     - T2/T3 自动出 PASS/FAIL；T2 打印的 `now=`/`CH` 用于 §5 断电保持人工核对。
    - T4 依次按 UP、SET（5s 内）。
    - T5 听蜂鸣；T6 看红灯闪；T7/T8 看 raw 值是否合理。
    - T9 自动擦/写读回 EEPROM 末扇区，出 PASS/FAIL（IAP 总线虚焊会 FAIL）。
 5. 末项 T10 为断电保持人工复核（见 §5）；其 `boot_action` 打印后，末行 `ALL PASS`/`FAIL mask=..` + 屏显 `0`/`E` 为最终判定。
6. 不合格板记录 mask 位 → 对应信号返修；返修后两键重测。

## 5. 断电保持测试（T10，人工步骤，置最后）

> DS1302 断电走时靠 CR1220 维持，固件无法自行切断主电源，故为人工操作，且排在全套测试最后。判定信号复用 `ds1302.c` 的 `g_ds_init_action`（与 `ds1302-clock` 已验证的断电走时逻辑一致）：上电首读 CH 位，0=保住走时 / 1=掉电停振 / 2=BCD非法。

1. 看 T10 打印的 `boot_action`：为 `0` 即电池保住走时，直接 PASS；为 `1`/`2` 则进入切电复核。
2. 切断整板主电源（拔 USB / 断 VCC），保持 **≥3 秒**。
3. 重新上电，冷启动进入 HWTEST，T9 再次打印 `boot_action`。
4. 判定：切电后 `boot_action=0` 且时间连续 → 断电保持合格；仍为 `1`/`2` 或时间归零 → CR1220 没电/反装（有字面应朝上）/虚焊 → 不合格。

> 风险说明：若不加人工核对，仅靠自动 T2，死电池会在上电后被 `ds1302_init()` 改写默认时间而**误判 PASS**；故 T9 必须人工确认时间未被重置。

## 6. 已知未覆盖项（产线/设计说明）

- **MCU 片内 EEPROM**：已通过 T9 自测（擦/写读回末扇区 0x1200，地址空间 0x0000–0x13FF、5K、扇区 512B；`IAP_CONTR=0x84` 按 11.051MHz 配 WT=100）。仅验证连通性/虚焊，不测擦写寿命与长期保持。
- **AMS1117-3.3 稳压**：MCU 由 +5V 直供（U3 pin12），故 1117 虚焊**不会**导致 MCU 停摆。但红灯 LED_T（LED7）阳极接 +3V3（§8），T6 要点亮须 +3V3 在场 → **1117 故障会表现为 T6 失败，被间接覆盖**。仅 ESP 侧（3.3V→ESP）仍超出 51 侧范围（ESP 按要求排除），靠成品模块/万用表确认。
- **绿灯 LED6（LED_W）**：由 ESP-01S 驱动（LED_W 网络在 MCU 修正版无对应引脚，§8），未连 MCU，**不可测**。
- **Micro USB 供电（+5V）**：板子能冷启动跑完 T1–T8 即隐含 5V 正常；由操作员确认上电。

## 7. 通过准则

- `FAIL mask=00` 且屏显 `0` 且双短音 → **合格**。
- 任一自动项失败（mask 非 0）→ **不合格**，按位返修。
- T1/T5/T6 若产线员肉眼/人耳确认异常，即便 mask=0 也应判定不合格（属人工复核项）。

## 8. 复用与定位

- 驱动直接复用 `demo/_common/`：`tm1639.c/.h`（显示）、`ds1302.c/.h`（时钟）、`stc15.h`（寄存器/ADC 宏）。
- UART 配置（Timer2 作波特源、9600、P3.1 推挽）沿用 `demo/uart-test` 已验证实现。
- 按键/蜂鸣/ADC 读法沿用 `demo/clock-bringup` 模式。
- 硬件引脚定义见 `plan/原理图.md` 与 `plan/固件复刻计划.md` §2。
